# Security policy

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/cogine-ai/begin-skills/security/advisories/new) for possible vulnerabilities in Begin. Include the affected version and Agent, the relevant file or command, required conditions, safe reproduction steps using synthetic data and likely impact.

Keep credentials, private project files, visitor data and exploit details out of public Issues and pull requests. If GitHub's private reporting action is unavailable, keep the details private until that channel is available. No separate security email or response deadline is defined.

## Scope

Reports may concern Begin's installation, update, removal, preview helpers or example boundaries. Identify whether the behavior comes from Begin, an Agent host, a third-party service or a website adapted from an example. Test only projects and data you control.

The current Alpha line is `0.1.0-alpha.5`. Security repairs are made in a new release; older fixed archives are retained for integrity and are not patched in place. Use the latest published release. Included examples have explicit teaching boundaries and need project-specific production security checks before handling real visitor data.
