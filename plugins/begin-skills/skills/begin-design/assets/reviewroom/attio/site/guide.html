01

Open the work

In the sample review, choose Landing page, Welcome email, or Product walkthrough. Check the version and status above the artwork before leaving feedback.

The sample starts with one item awaiting review, one with changes requested, and one approved.

Open the sample review ↗
02

Leave a specific comment

Write in Your feedback, then choose Add comment. A useful note names the part of the work, explains the concern, and gives a clear next step.

“In the welcome email, move the first step above the introduction so it is easier to find.”

A comment is added beside the selected version. It does not change the item's decision. Keep each note to 2,000 characters.

03

Make the next decision

To ask for an edit, write your feedback first and choose Request changes. The comment is saved and the item's status changes to Changes requested.

When a version is ready, choose Approve version. The status and approved count update immediately. The button is disabled while that version is approved; you can still request changes with a new comment.

04

Return to the same sample

Comments and decisions are saved in this browser for this direction. Reload the page or come back later to see your sample state. Unsaved draft comments stay with each item while this page remains open; submit a comment to save it across reloads.

If browser storage is unavailable, an on-page message explains that changes last only for the current page.

05

Start again

Choose Reset sample at the bottom of the review workspace. This direction's comments and decisions return to the original state. Other sample directions are kept separate.

This is a fictional product concept. No account, upload, payment, backend, or client transmission is connected. Use sample feedback only.
