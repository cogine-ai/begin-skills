STEP 01

Open a version

The sample project, May launch, contains three pieces of work. Choose Landing page, Welcome email, or Product walkthrough to see its current version, status, and feedback.

Each item starts in a different state: awaiting review, changes requested, or approved. The work is original sample artwork. You cannot upload or replace files in this trial.

STEP 02

Leave useful feedback

  1. Choose the item you want to review.
  2. Write a specific note in Your sample feedback.
  3. Select Add comment to record the note beside that version.

Adding a comment keeps the current status. To ask for a revision, write the required comment and select Request changes. The item then changes to Changes requested.

Empty comments are rejected. Notes can contain up to 2,000 characters. Switching items keeps each unfinished note for the current page. Add the comment to save it across reloads.

STEP 03

Confirm the next step

Select Approve this version when the selected work is ready. Its status becomes Approved, and the approved count updates. The button is disabled for a version that is already approved.

You can still leave a note on an approved item. If a later comment identifies a required revision, use Request changes to return it to that state.

These are sample decisions. No message, invitation, or approval is sent to a client or teammate.

STEP 04

Return or start again

Comments and decisions are stored locally for this sample direction. Reloading the page restores them when browser storage is available. This is not account storage: another browser or device will not receive the changes.

Select Reset this sample to remove this direction's saved review and return all three items to their starting states. The other visual directions keep their own sample state.

If browser storage is unavailable, the status message tells you that changes will last for the current page only. A reload can then return the sample to its starting state.

STEP 05

What this sample includes

You can select three files, add feedback, request changes, approve a version, reload saved local state, and reset it. All names, work, and starting comments are fictional.

This trial has no account, upload service, payment, server storage, client transmission, or public deployment. Use sample comments rather than private client information.
