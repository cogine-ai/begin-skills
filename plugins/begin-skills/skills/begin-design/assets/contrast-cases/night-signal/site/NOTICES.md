# Night Signal credits and notices

Night Signal is an original fictional community astronomy weekend made for an internal Begin design trial on 11 October 2026. Its event identity, six-session programme, fictional hosts and stations, copy, HTML/CSS/JavaScript and two SVG artworks were created for this site. The orbit field is graphic art, not an accurate star chart. No real venue, actual event, booking or weather service is represented.

No external photographs, logos, reference screenshots, website code or real participant records are included. The website has no runtime remote requests. The planner keeps an explicit version in browser-local storage and downloads a text file; it has no backend, ticket, reservation, payment or calendar service.

The frozen internal Begin dev.13 pack supplied design guidance, reference source/captures and the font files below. The relevant references were studied for their content relationships. Their example source code, brand copy and artwork were not copied into this site. This notice grants no new public redistribution license for the original site or the internal Begin pack.
