Prepare a four-session weekend

Use Find north and Beyond the naked eye on Friday, then Lunar sketchbook and Deep sky circle on Saturday. You will get 270 minutes in sessions with 120 minutes between sessions.

Open this four-session plan ↗

This link sets those four choices and an empty field note. An existing kept version remains available; you can start this exercise without forgetting it.

  1. Check the four named sessions. A binocular atlas and Your first telescope should be unchecked.
  2. In My field note, enter “Bring a warm layer and a red-light torch.”
  3. Select Prepare itinerary. The result becomes Current · ready to keep or download and shows the following chronological plan.

Leave room for each session

Add A binocular atlas to the four-session example. Both it and Find north receive conflict feedback; the planner names their shared time. A previous itinerary remains visible, with an out-of-date label.

Friday 6 Nov · Find north + A binocular atlas
Overlap 19:00–19:15 · 15 minutes

Selecting Prepare itinerary with that clash leaves the previous result intact and moves focus to the correction message. Uncheck one session from the pair and prepare again. No session is removed automatically.

The Saturday clash is Lunar sketchbook with Your first telescope, overlapping 18:30–19:00 for 30 minutes. Friday and Saturday choices are checked independently, so the same clock time on different days is allowed.

Make the next version current

After preparing the four-session example, uncheck Deep sky circle. The old four-session result remains visible as Out of date · prepare again. Both Keep in this browser and Download text become unavailable.

  1. Select Prepare itinerary again. The new result has 3 sessions, 180 minutes in sessions and 60 minutes between sessions.
  2. Friday still runs 18:30–21:30. Saturday now contains only Lunar sketchbook, 18:00–19:00.
  3. Change your field note. This also makes the prepared result out of date. Prepare once more to include the new wording.

Returning a checkbox or note to its previous value still requires preparation again. A kept version is separate: none of these edits changes it until you choose “Keep in this browser.”

Clear current choices unchecks every session and empties the note. It leaves any previous result visible and out of date, and preserves your kept version. An empty selection cannot be prepared.

Keep a version you can return to

Prepare a current result, then select Keep in this browser. The kept summary names its session count, session minutes and time kept. This replaces the last kept Night Signal version for the same browser and site address.

Reload the page
The itinerary page restores the last kept choices, note and prepared result. Edits made after keeping disappear on reload.
Reload kept version
Restores that same kept version immediately, replacing the current choices, note and prepared result. The result is current again.
Forget kept version
Opens a short confirmation. Choose “Forget it” to remove the stored version. Current choices and the result stay on the page. Choose “Keep kept version” to cancel.
After forgetting
The current itinerary can still be downloaded or kept again if it is current. Reloading the page starts empty because no kept version remains.

For a recovery exercise, keep the four-session example, then remove Deep sky circle without keeping again. Select Reload kept version; all four sessions and the kept field note return, with 270 session minutes and 120 break minutes.

Storage belongs to this browser profile and site address. Another device, private window or serving address has its own storage. Clearing browser data can remove your kept itinerary. A downloaded file gives you a separate copy.

Carry the actual text

With a current prepared itinerary, select Download text. Your browser downloads night-signal-itinerary.txt, a UTF-8 text file containing the exact prepared session order, times, stations, hosts, day spans, totals and field note. It also states that the event is fictional.

The four-session example includes these totals and note:

TOTALS
Sessions: 4
Session time: 270 minutes
Between sessions: 120 minutes (within each day only)

FIELD NOTE
Bring a warm layer and a red-light torch.

Open the file and compare it with the prepared result. Downloading does not keep a version in this browser, send it to anyone, create a calendar event or reserve a place. If you change a choice or note, prepare again before downloading the new text.

Find your way back

Nothing prepared
Select at least one session, then “Prepare itinerary.” If all choices are empty, the correction message stays beside that action.
A conflict remains
Read the named pair and exact shared time. Uncheck one of those sessions, then prepare again. Your previous result remains available to inspect.
Keep fails
The page reports that browser storage could not be written. Your current result remains usable. Download text for a separate copy; retry keeping if storage access becomes available.
Kept data is unreadable
The planner does not restore an invalid record. Choose fresh sessions, or use “Forget kept version” to remove the unreadable stored record. The invalid data is not silently changed.
Another tab changes it
The kept summary updates while your current work stays on the page. Use “Reload kept version” to adopt the latest valid kept version.
Download seems missing
Check the browser’s downloads list and download permissions. Make sure the result is current; stale results keep the download button unavailable.
JavaScript is off
The home programme and guide still explain the weekend. Enable JavaScript and reopen the itinerary page to select, prepare and use local recovery.

The planner uses six fixed fictional sessions. It has no live weather, availability, capacity, accessibility service, organizer connection or actual venue data. The sky artwork is original event graphics, not an accurate observing chart.
