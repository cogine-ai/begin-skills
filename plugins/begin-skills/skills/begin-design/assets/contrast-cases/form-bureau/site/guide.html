02 / READ THE MEASUREMENTS

Three dimensions, one footprint

Width runs across the object. Depth runs from front to back. Height describes its highest point. The catalogue always uses W × D × H; 310 × 245 × 465 mm means 310 mm wide, 245 mm deep and 465 mm high.

Use width and depth together when thinking about a surface. A 260 mm deep shelf leaves only 15 mm beyond Arc’s 245 mm exterior depth. Arc’s planning note also asks for 80 mm behind the base for a cord, so the exterior number alone is insufficient. Fold’s 195 mm depth leaves 65 mm on that same shelf.

Drawings show character and construction. They are not scale templates, dimensioned engineering drawings or proof that an imagined object will fit. Organizer dimensions describe its exterior; internal compartment sizes are not supplied.

Leave room for use

A rack holds papers beyond its frame. A lamp needs space above and behind it. Read each object’s planning note before deciding which dimensions matter.

03 / SEARCH AND COMPARE

Change the view, keep the set

Use Desktop, Seating or Storage to narrow the catalogue. Main material groups records by their primary material: Arc is grouped as Aluminium even though its base also uses steel. The full material stays visible in the card and comparison.

Find an object matches its name, record number, material and archive status. Search, category and material combine. For example, Desktop plus Aluminium shows Arc and Fold.

Filters never remove selected objects. Select Arc, choose Seating, and Arc remains in your working comparison. Select Frame there to compare both. No objects match these filters means only that the current view has no matches; Show all objects clears the filters.

Remove from shortlist removes one object. The comparison’s Remove action does the same. Clear selections removes every selection and marks a prepared result stale. It preserves the workspace name, note and kept version.

04 / PREPARE CURRENT WORK

Know which version you are using

Current

The prepared sheet matches your present selection, workspace name and note. Keep and Download use this sheet.

Stale

Something changed after preparation. The earlier sheet remains visible, while Keep and Download are blocked.

Try the first example, then remove Fold. Your working comparison now has one object, while the prepared sheet still shows two. Its status is Stale. Choose Prepare shortlist again to replace it with a new numbered version containing Arc alone.

Editing the name or note also marks work stale. Even if you change the text back, prepare again to confirm the new input revision. Search and filters do not change preparation status.

You must select at least one object and enter a workspace name. Names allow up to 60 characters; notes allow up to 600. An invalid preparation keeps the previous sheet visible and reports what to correct.

05 / KEEP AND RECOVER

Keep one local version

Keep in this browser
Stores the current prepared selection, name and note. It replaces the previous kept version. No other browser or device receives it.
Reload kept work
Replaces the working inputs and prepared sheet with the kept version, and clears filters. Unkept changes are discarded.
Browser reload
Reloading the working catalogue page restores the last kept version automatically. If none is kept, it starts with no selections, “My workspace” and an empty note.
Forget kept work
Removes the local saved record. The selection and prepared sheet currently on screen remain visible. A later page reload starts empty.

For a recovery exercise, prepare the North desk example and choose Keep. Remove Fold and edit the note. The prepared sheet becomes stale, but the kept status still names the two-object version. Choose Reload kept work: the two objects and Keep the shelf edge clear. return, with Current status.

Local storage can be unavailable in private browsing, restricted browser settings or some file-opening contexts. If keeping fails, the page reports it and your visible work stays intact. Download a current text file before closing the page. Clearing site data or changing browser profiles can remove kept work.

06 / DOWNLOAD YOUR RECORD

A plain-text study to take away

Prepare your current inputs and choose Download text. The browser creates a UTF-8 form-bureau-shortlist-v01.txt file for prepared version 01; later versions use their own number. Browser download settings may choose where it goes or prompt you for a location.

The file includes the prepared version, catalogue revision, workspace name, selected count, every full object name, exact W/D/H dimensions, material, finish, illustrative USD price, archive status, planning note and your workspace note. It ends with the fictional research limits. It contains no hidden order or payment information.

07 / WHEN SOMETHING CHANGES

Return to useful work

My objects disappeared
Check the selected count and comparison first. A filter hides records without removing them. Choose Show all objects or return to All objects and All materials.
Download is unavailable
The sheet is unprepared or stale. Correct the inputs if needed, then choose Prepare shortlist. At least one object and a workspace name are required.
Kept work cannot load
The stored record is damaged, has been altered or belongs to a different catalogue version. The page refuses it and starts clean. Forget kept work removes that stored record; prepare and keep a new one.
Keep or Forget failed
Storage was blocked by the browser. Current visible work is preserved. Use Download text for a current version, then check browser storage permissions.
I accidentally reloaded
Reload kept work if a kept version exists. Unkept selections and notes cannot be recovered. A previous text download may still contain your research, but it cannot be imported automatically.
Another tab changed kept work
This page reports the storage change. Reload kept work reads the latest valid saved record. Current work stays visible until you choose that action.

Shared computers share browser storage within a browser profile. Avoid sensitive personal details in workspace notes. Forget the kept version when you are finished on a shared device, and handle downloaded text separately.

08 / WHAT THIS ARCHIVE MEANS

Research, then reality

Form Bureau is a fictional collection. Every object, dimension, material, finish, price and archive status is invented for this local study. The six illustrations are original SVG specimens, not photographs of manufactured stock.

Study edition, Reference form and Archive record distinguish imagined curatorial records. None indicates availability, provenance, authenticity, rarity or a promise to supply an object.

A shortlist records consideration. A purchase would require a real seller, verified specification, current availability, commercial terms and a payment flow. None exists here. There is no order, quote, reservation, delivery, enquiry, account or remote synchronization.

These dimensions cannot establish electrical safety, stability, load capacity, ergonomic suitability or compliance. The clock is static. No real products or prices are being recommended. Browser-local keeping and text download are the full task.
