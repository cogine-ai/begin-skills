Prepare for eight

Enter 8 servings for Lemon & olive oil cake and select Prepare worksheet. Compare your prepared quantities and optional note with the ingredient sheet below.

Open the worksheet for eight ↗

The link sets the servings field to 8. If you already kept a version, it remains available. You can start without resetting it.

Add an optional note, such as “Bring the green plate”. After preparation, check for “Prepared for 8 servings · Current” above the quantities. Your note should appear below them.

Keep a version for later

With the current sheet prepared, select Keep in this browser. The message names the servings you kept. This replaces any earlier kept version in this browser.

Reload the page. Your kept servings, note and prepared quantities return together. A new draft is separate from that kept version: changing a field does not silently save it.

Restore kept version brings back the last kept sheet and its inputs. Use it when you want to discard the current edits and return to that version.

A browser can block or clear local storage. If keeping fails, the page says so. Download a current worksheet if you want a file outside this browser.

Let a change become a new sheet

Change the servings from 8 to 6, or edit the note. The prepared sheet stays visible, but its status becomes Stale. It still shows the last preparation’s values.

Keeping and downloading are blocked while the sheet is stale. Select Prepare worksheet again to update it. For 6 servings, the eggs become 3 whole and the flour becomes 270 g. The current note appears with the new quantities.

Even if you change a field back to its previous wording, prepare again before keeping or downloading. This makes the step explicit: the sheet represents the inputs you last prepared.

Correct an entry without losing it

Try 7 in the servings field and select Prepare worksheet. The field keeps your entry and asks for an even number. The last prepared quantities remain visible and marked stale.

Change 7 to 8 and prepare again. The error clears, the quantities update, and keeping and downloading become available.

Download the text; start again when needed

Select Download text when the sheet is current. The file includes the recipe title, serving count, six ingredient quantities and your prepared note. Open the file and compare it with the sheet you see.

The file reflects the current preparation. It does not substitute an older kept version. If you edit anything first, prepare again before downloading.

Reset worksheet clears the current note, prepared sheet and this browser’s kept version. The input returns to 4 servings and the result becomes empty. Use reset when you want a fresh starting point; it is not required before following this guide.

A text file you already downloaded remains on your device after a reset.

A small ratio, kept readable

The starting list is for 4 servings. Every amount is multiplied by the requested servings divided by 4. Eight servings gives a factor of 2; two servings gives a factor of ½.

The worksheet accepts only the six even serving counts from 2 through 12. The original 2 eggs therefore become 1, 2, 3, 4, 5 or 6 whole eggs. Flour and sugar remain in grams; olive oil, milk and lemon juice remain in millilitres.

The result is an arithmetic ingredient list. It does not decide a pan size, baking time or technique. Scaling ingredients alone does not establish a tested baking result.
