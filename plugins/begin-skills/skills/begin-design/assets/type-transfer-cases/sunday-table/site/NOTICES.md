# Sunday Table asset notices

Sunday Table is a fictional cooking journal. Its original example writing, HTML, CSS, JavaScript and hand-authored SVG illustrations were created for this Begin forward-use trial on 11 October 2026. The recipe list is an illustrative calculation exercise, has not been kitchen-tested, and includes no baking method. The artwork does not depict a tested recipe result.

## Method references

The frozen Begin dev.11 pack supplied professional design methods and inspected original reference captures. No reference artwork, font, stylesheet or script was copied into the website. The consumed input manifest remains with the raw development study and is excluded from this portable site.

## Local behavior

This example has no backend, account, checkout, telemetry or sending. Keeping writes one ingredient worksheet into this browser's local storage. Downloading creates a local plain-text file. Reset affects only this example's local worksheet key.
