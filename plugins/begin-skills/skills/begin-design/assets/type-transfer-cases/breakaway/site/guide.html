01 / Make the sheet

60 km. 150 minutes.
Back at 10:30

Set Distance to 60 km, Target pace to 24 km/h, and Start time to 08:00. Prepare a worksheet to get 150 minutes of moving time and an estimated finish of 10:30.

Open the 60 km example ↗

The link sets those three editing inputs. Your previously kept worksheet remains available. You can begin without resetting it.

  1. Check the three labeled inputs: Distance 60, Target pace 24, Start time 08:00.
  2. Select Prepare worksheet. Read the current result:
Moving duration150 min

2 h 30 min

Estimated finish10:30

Same day

The formula is 60 ÷ 24 × 60 = 150 minutes. The start time plus 2 hours 30 minutes gives 10:30. Stops are not included.

02 / Keep & recover

Keep it for later

  1. With the current result visible, select Keep in this browser. This replaces the one earlier Breakaway worksheet kept in this browser.
  2. Check the confirmation. It should name 60 km, 24 km/h, 08:00 → 10:30 and 150 minutes.
  3. Reload the page using its plain Pace sheet address. The three inputs and the prepared result return. Reload kept version also restores that same snapshot while you are editing.

Keeping is explicit. Editing and preparing do not replace the kept version. A different browser or device does not have this copy. If browser storage is blocked, the current prepared sheet can still be downloaded.

03 / Correct an edit

Change it. Prepare again

  1. After preparing the 60 km example, change Distance to 60.5. Your previous sheet stays visible and is marked Stale — inputs changed. Keeping and downloading are unavailable.
  2. Select Prepare worksheet. The distance error should say Enter a whole number from 10 to 200 km. The edit and the old result both remain.
  3. Correct Distance to 90. Keep Target pace 24 and Start time 08:00. Select Prepare worksheet again.
  4. The new result is 225 minutes (3 h 45 min), finishing at 11:45 on the same day. Keeping or downloading is now available.

Every edit requires another preparation, even if you type the old value back in. Invalid inputs never replace a successful sheet or your kept snapshot.

Across midnight

Use 60 km, 24 km/h, 23:00, then prepare. Expect 150 minutes, finishing at 01:30 — next day.

04 / Download & reset

Take the text with you

With a current prepared sheet visible, select Download text. Open breakaway-pace-sheet.txt from your downloads. It contains the current distance, target pace, start time, whole-minute duration, finish time and same-day or next-day label.

Reset when you want a clean sheet

Reset worksheet removes the kept browser snapshot, restores 60 / 24 / 08:00 to the inputs, and clears the prepared result. Prepare again to calculate. A text file already downloaded is a separate copy and stays on your device.

05 / Local scope

A small, local tool

Distance accepts whole numbers from 10 to 200 km. Target pace accepts whole numbers from 10 to 40 km/h. Start time uses the 24-hour format HH:MM, from 00:00 to 23:59.

Breakaway is fictional. The route illustrations are invented and cannot be used for navigation. The worksheet performs arithmetic; it does not assess route safety, fitness, traffic, weather, stops or delays.

The tool sends nothing and uses no account or analytics. Browser storage holds one worksheet you explicitly keep. Clearing website data removes that copy.

Storage, recovery & source details

The snapshot uses breakaway.pace-sheet.v1. Its inputs are checked and its result recomputed on recovery. An unreadable record is not used; prepare and keep a new sheet to replace it. If storage fails, the page reports that failure and leaves your current result available.

Use a local static server for a consistent browser origin. Storage policies for directly opened local files and private browsing can differ.

The pace model owns arithmetic and worksheet states. The interface script connects controls, local storage and the text download. Font licenses and artwork attribution are in credits & notices.
