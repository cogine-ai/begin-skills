03 / Correct the input

Use whole digits

Monthly API calls accepts an integer from 0 to 1000000. Enter 18000, rather than 18,000. Empty input, words, decimals, negative values and values above 1000000 cannot be prepared.

Try
Replace 18000 with 18000.5, then choose Prepare estimate.
Expected
A call-count error appears beside the field. The entered text stays intact. The last successful statement stays visible, marked Stale; keeping and downloading are unavailable.
Correct
Enter 18000 and choose Prepare estimate again. Basic is USD 20.00, and the new statement is Current.

Returning to a previous value still counts as an edit. Prepare again to confirm that the statement reflects the selected values.

05 / Retain the version

Keep, edit, reload

  1. Keep the Current Scale statement

    Choose Keep estimate. The kept line names its version, Scale, 60,000 calls and USD 44.00. Read the storage note to confirm the browser can retain it.

  2. Try an unsaved edit

    Enter 61000. The current calculation becomes USD 44.75, while the previous prepared Scale statement stays USD 44.00 and becomes Stale. The kept line still names 60,000 calls.

  3. Reload on the same site origin

    When browser storage is available, Scale and 60000 return with the kept USD 44.00 statement, marked Current. The unsaved 61000 edit is discarded.

Keep replaces the one previously kept estimate. Storage belongs to this browser, profile and site origin. Another browser or port can start fresh. When storage is unavailable, kept work lasts only for the current page.

06 / Take the actual statement

Download the Current summary

Choose Download summary while the statement is Current. The text file contains the exact plan, monthly calls, allowance, excess, begun blocks, base fee, excess cost and monthly total from that prepared version.

The full file also includes its prepared version and the illustrative-rate boundary. Its filename includes the plan, call count and version, such as relay-scale-60000-v02.txt. Your version number depends on how often you prepared.

A download is separate from keeping an estimate. It does not change browser storage. Editing the selected values blocks download until you prepare them again.

07 / Recover deliberately

Reset when you need a clean start

Choose Reset estimator to clear this estimator’s selected values, last prepared statement and kept browser record. Basic and 18000 are restored. There is no prepared statement until you prepare again.

The estimate did not survive reload

Read the storage note. Browser storage may be blocked or cleared. A different origin, port, browser or profile also has separate storage. Download a Current statement before leaving when local retention is unavailable.

The prepared values look older than my selection

Read the Selected values and Last prepared statement labels. An edit leaves the previous statement in place, marked Stale. Choose Prepare estimate to make the new values Current.

A stored estimate cannot be read

The estimator rejects an invalid or incompatible kept record and opens the original Basic sample. Prepare and keep a new estimate to replace it, or Reset estimator to clear it.

Can this calculate my actual provider’s bill?

The two rates are illustrative and fixed. The estimator has no provider connection and models no taxes, discounts, retries, regional pricing or additional services. Entered calls are a sample count, not a verified usage measurement.
