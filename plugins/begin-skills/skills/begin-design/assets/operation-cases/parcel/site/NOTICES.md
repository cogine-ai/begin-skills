# Parcel notices

Parcel’s HTML, CSS, JavaScript, copy and geometric artwork were created originally for this local Begin Skills task. No existing starter or reference component source was copied. The five piece definitions and board fixture were supplied as game facts by the task.

## Fonts

Space Grotesk and IBM Plex Mono are unmodified, locally served font files from the frozen input pack. Their full SIL Open Font License notices are in `fonts/SpaceGrotesk-OFL.txt` and `fonts/IBMPlexMono-OFL.txt`. `FONT_SOURCES.json` preserves each binary and license source URL, original byte count, SHA-256 and portable frozen origin. Font licenses remain separate from original site material.

No external image assets, runtime services, CDN resources or new package dependencies are used.
