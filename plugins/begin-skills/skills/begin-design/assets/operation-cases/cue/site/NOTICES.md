# Font notices

Cue uses Space Grotesk for names, instructions and controls, and IBM Plex Mono Regular/Medium for times and cue positions. These three unchanged local font files remain under the SIL Open Font License 1.1. Complete copyright and license notices accompany both families in `notices/SpaceGrotesk-OFL.txt` and `notices/IBMPlexMono-OFL.txt`.

`FONT_SOURCES.json` records the exact copied files, relative frozen-input provenance and SHA-256 hashes. The original frozen source URLs and ledger are retained in `notices/SOURCE-SignalDesk.json`. No network font retrieval, outside components or outside site source were used. Rejected candidate assets are retained in the separate historical type study, outside this runtime site.
