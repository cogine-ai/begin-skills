Compare LP02 with LP05

Open the fit workbench in a browser with JavaScript enabled. You need no account. This exercise prepares a complete record that you can keep, reload and export.

Mounting centres96 mm

Panel thickness20 mm

  1. Enter 96 in Mounting centres and 20 in Panel thickness. Choose Find matching pulls.

    Two components fit: LP02 and LP05. Matching results also update as you enter valid measurements.

  2. Choose Add to comparison + on LP02 and LP05.

    Each button says “Selected for comparison −”. Select it again to remove that component.

  3. Choose Prepare comparison (2).

    The prepared comparison shows the requested dimensions once, then each full component name and its labelled facts. Open Inspect exact export text to read the text that the export will contain.

  4. Choose Keep comparison locally.

    The separate kept area shows the 96 mm / 20 mm comparison. If a comparison was already kept, this replaces it.

  5. Reload, then choose Recover kept comparison.

    The measurements, selected components and prepared text return. Keeping happens only when you request it.

  6. Choose Export exact text.

    Your browser downloads latch-parts-comparison.txt, containing exactly the prepared text below, including the final newline. The fixture text file is available for byte comparison.

Understand the dimensions

Mounting centres
The distance between the centres of the mounting holes. Enter a positive whole number of millimetres. A part matches only when this equals its listed centres.
Panel thickness
The panel's thickness in whole millimetres. The input accepts 1–60 mm. A component matches when your value is within its listed minimum and maximum, including both endpoints.
Overall width
The component's full width. It appears in the comparison but is not a fit filter.
Projection
The listed outward depth of the component. It appears in the comparison but is not a fit filter.

LP02 and LP05 both fit 96 mm centres and a 20 mm panel. LP02 is 124 mm wide with 32 mm projection. LP05 is 116 mm wide with 34 mm projection. At 25 mm panel thickness, only LP02 fits.

Keep, recover or forget a comparison

Prepare comparison creates the text from one or two currently selected matching parts. Preparation alone does not keep anything after reload.

Keep comparison locally writes one snapshot to this browser's storage. It replaces the previous kept comparison. Editing your input or preparing another comparison does not change that snapshot until you keep again.

Recover kept comparison restores the kept measurements, chosen parts and exact text into the workbench. The kept text is checked against the catalogue before it is accepted.

Export exact text downloads the current prepared text as latch-parts-comparison.txt. Export kept text downloads the separate snapshot as latch-parts-kept-comparison.txt. Both use UTF-8 text, LF line endings and a final newline. Invalid current input pauses both exports; recover the kept comparison to restore valid measurements.

Forget kept comparison removes the snapshot from this browser. It leaves your current inputs and prepared text in place. If you also want an empty workbench, reload after forgetting.

If storage does not work

The page reports a storage failure without claiming the record was kept or forgotten. Your prepared text remains available. Export it while the inputs are valid. Use Check browser storage to retry reading after correcting browser settings. If a kept record is damaged, the workbench rejects it and offers forgetting instead of trusting its contents.

Change or correct measurements

Use positive whole numbers such as 96 and 20. Zero, negative numbers, decimals, exponent notation, letters and empty fields are invalid. Panel thickness above 60 mm is invalid. Extremely large centre values that the browser cannot represent exactly are rejected.

Upper input limit

The largest accepted mounting-centre input is 9007199254740991 mm. Larger whole numbers are rejected because the browser cannot represent them exactly.

A valid change to either measurement clears the current selections and prepared comparison. This prevents an earlier result from being kept or exported as if it came from the new dimensions. Your deliberately kept comparison stays separate.

An invalid change preserves the previous prepared text and selected parts. The page shows errors beside the affected fields and disables selection, preparation, keeping and both exports. Correct the input to continue. Restoring the previous valid values makes the preserved comparison available again; entering different valid values starts a new comparison.

With no matching components, the page reports “No matches” and the requested values. It does not substitute the nearest centre distance or widen a thickness range. Try a different measured value only if it reflects the panel you are checking.

Local example & privacy

Latch Parts is a fictional independent maker, and the website owner is the catalogue publisher. The visitor may be a furniture maker or home renovator. These six records are supplied demo dimensions, rather than verified manufacturing specifications.

This example takes no orders or payments and checks only centre equality and inclusive panel-thickness ranges. It does not establish fit tolerances, fastener specifications, load capacity, installation safety, availability or finish choices. Use a real maker's specifications before choosing a physical component.

Inputs, selections, comparison text and the explicitly kept snapshot stay in this browser. The site sends no API requests, analytics, feedback or visitor content. Fonts and artwork are local files. There is no account or cross-device recovery.

Browser storage belongs to the current site origin and browser profile. A different browser, private window, changed site address or cleared site data can make the kept comparison unavailable. Private browsing may discard it when the session ends. Direct file openings may treat storage differently; a local HTTP preview provides a stable origin. Export a text copy if you need a record outside that browser.

Third-party font licenses and exact source records are included in the site notices. This local example has not been deployed.
