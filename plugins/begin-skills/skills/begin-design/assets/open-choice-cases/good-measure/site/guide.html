Prepare a list

On Make a cut list, enter a Project name, then choose at least one fabric. Enter a length for each selected fabric. Add a Project note if it will help you remember the plan.

  1. Select Prepare cut list.
  2. Review the full fabric names, widths, fibres, lengths and costs in your prepared result.
  3. Choose Download exact text to take a file away, or Keep in this browser if you want to recover the list here later.

Preparing and keeping are separate. A prepared list is held in the current page until you deliberately keep a copy or download it. Reloading loses unkept work.

Lengths and totals

For each selected fabric, enter 0.25 to 5.00 metres, including those endpoints, in 0.25 metre steps. Valid examples include 0.25, 0.50, 1, 1.25, 2.5 and 5.00. Use a decimal point. Fractions, commas, negative lengths, 0, 5.25 and 1.10 are invalid.

Each cut's cost is its length multiplied by the fabric's price per metre. The total length adds the selected lengths; the total cost adds their costs. The calculation uses whole centimetres and pence, then displays two decimal places.

2.50 m × GBP 14.00 / mGBP 35.00

Fabric widths are recorded with each cut. They do not change the length or cost calculation. No taxes, delivery charge, discounts, seam allowances or stock reservation are calculated. Prices and stock are fictional demo facts.

The project name is required and can use up to 80 characters on one line. The optional note can use up to 500 characters. Leading and trailing spaces are removed when the result is prepared. Internal note line breaks are preserved.

Make a change

Change a fabric choice, length, project name or note at any time. An existing result becomes Changes need preparation. It stays visible as the earlier result while Keep in this browser and Download exact text are paused.

Select Prepare cut list again to replace the earlier result with the current values. Even if you change a field back to its original value, prepare again to confirm the list.

If preparation finds an invalid field, it marks the field and keeps what you entered. Any earlier prepared result stays unchanged. Correct the marked fields and prepare again before keeping or downloading.

Keep and recover

After preparing a valid current result, select Keep in this browser. This stores exactly that list in this browser on this site. It replaces any previous kept copy. Changing or preparing the current form does not replace the kept copy by itself.

  1. After a reload, the form starts blank. Under A copy for later, the page identifies a kept copy if one exists.
  2. Select Recover kept list. Recovery replaces the current form and result with the verified kept list.
  3. Review or download the recovered list. If you edit it, prepare again before keeping or downloading the changes.

Reset current form clears the current form and result while preserving the kept copy. Forget browser copy removes only the kept copy; it leaves the current form and prepared result unchanged.

A kept copy stays in this browser on this site. Another browser or device will not have it. Clearing website data removes it. Private browsing or browser restrictions may prevent keeping. Download a text file if you need a record you can move yourself.

Exact text export

Download exact text creates a plain text file from the current prepared result. It preserves the full fabric names, IDs, widths, fibres, lengths, prices and cut costs, as well as totals, project name and note. Fabrics appear in catalogue ID order, GM01 through GM06.

The file matches the text shown under Inspect exact export text. The filename is based on the project name. Downloading does not keep a browser copy or submit anything to the shop.

If something goes wrong

“Enter 0.25–5.00 m…”
Use a valid quarter-metre length and a decimal point. A selected fabric cannot have an empty length. Unselected fabrics are ignored.
The download or keep button is paused
Prepare a valid current list. Editing a prepared list pauses those actions until you prepare again.
The browser could not keep the list
The prepared result stays available. Download the exact text instead. Browser storage may be blocked or full.
A kept copy could not be verified
The current form stays unchanged. You can forget the unusable browser copy and keep a fresh valid list. A corrupted copy is not loaded into the form.
There is no copy after reload
Only a deliberate keep survives reload. Check that you are using the same browser on this site. If browser data was cleared, recover from your own downloaded text as a reference by entering the values again; file import is not provided.
