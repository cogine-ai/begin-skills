01 Prepare a handout

Open Make a handout in a browser with JavaScript enabled. Enter a handout name and select one, two or three games. Add a teaching note if you want one.

Choose Prepare handout. The prepared handout includes the full game names, IDs, demo dates, player ranges, estimated durations and complete supplied rules. A total adds the estimated minutes for playing the selected games one after another.

Look for Prepared, your handout title, the sequential play total, and every game’s complete rules. Games appear in accession order, AP01 to AP06, regardless of the order you clicked them.

02 Change the working handout

Edit the name, selections or note. The existing prepared text stays visible, with Changes need preparation. Choose Prepare handout again to replace it with text from your new input.

If the name is blank or the selection has fewer than one or more than three games, preparation shows an error and preserves the previous text. Correct the input and prepare again. Keeping and downloading are blocked while the text is stale or input is invalid, even if you undo your edit.

03 Keep deliberately, then recover

To keep a local copy for later, choose Keep in this browser after preparation. This browser keeps one copy for this site, replacing your previously kept handout. Typing and preparing alone do not keep a copy.

After a reload, unsaved working changes are lost. The working fields start empty; a link from the collection can preselect its game. The kept copy is available in Your kept copy. Choose Recover kept handout to replace the working draft and prepared text with that copy. You can then edit, prepare, keep or download it.

The copy is kept only when the page reports Kept in this browser. Check its name before reloading. If keeping fails, your previously kept copy stays unchanged.

04 Download the exact text

With a current prepared handout, choose Download exact text. The browser downloads archive-of-play-handout.txt, a plain text file containing your prepared handout. Keeping a browser copy is optional.

To inspect the exact file contents before downloading, open Read exact export text below the formatted handout. If your browser asks where to save the file, choose a folder you can find.

Technical note for exact comparisons +

The downloaded file is UTF-8 text, with LF line endings and one final line ending. Its bytes match the exact export text. The reference example below uses the same format.

TEACHING NOTE
Read each rule aloud before starting.

1. Turnfold (AP01)
Demo date: 1932
Players: 2–4
Estimated play time: 10 minutes
Rules: Fold the board into four fields. On each turn, move one counter to a neighbouring field. The first player to return all three counters to the starting field wins.

2. Clockwork Meadow (AP02)
Demo date: 1967
Players: 2–6
Estimated play time: 15 minutes
Rules: Lay the six meadow tiles in a ring. Rotate one tile on each turn and follow its marked path with a wooden piece. Collect three different leaves before returning to the gate.

3. The Quiet Line (AP03)
Demo date: 1984
Players: 1–3
Estimated play time: 20 minutes
Rules: Place twelve stones along the printed line. Move one stone past exactly one neighbour each turn. Finish with four separate groups of three stones.

To test keeping, choose Keep in this browser, reload and recover. To test stale text, change the teaching note: downloading is now blocked until you prepare again.

06 Reset or forget

Reset working handout clears the current name, selected games, note and prepared text. It leaves the kept copy available for recovery.

Forget kept copy explicitly removes that site’s kept handout from this browser. It leaves the current working handout intact. To clear both, reset the working handout and forget the kept copy.

07 Know the local scope

Archive of Play is a fictional museum. Its entries, demo dates and object drawings are invented teaching material. They do not describe historical objects or represent a real institution.

Your handout is prepared on your device. Keeping is optional and leaves one copy in this browser. The archive receives neither your handout nor your teaching note. Download a text file when you want a separate copy.

A kept copy is available only in the browser profile and site address where you kept it. Private browsing, cleared site data, blocked storage, another browser or a different site address may make it unavailable. Someone using the same browser profile on a shared device can read it. Keep only suitable teaching material.

If something goes wrong

Preparation reports an error
Enter a nonblank name and select one to three games. Your previous prepared text remains available to read. Correct the fields and prepare again.
The keep action fails
Your browser may block local storage. The current text stays visible; download it while it is current. Any older kept copy is not intentionally removed.
A kept copy cannot be read
The stored record may be damaged or belong to an incompatible format. Recover is blocked. Use Forget kept copy to remove it, then prepare a fresh handout.
A downloaded file did not appear
Check the browser’s downloads or download permissions. A message says the download was requested; it does not verify where the browser saved the file.
JavaScript is off
The collection and this guide remain readable. Enable JavaScript for the handout maker, or use the downloadable reference example.
