02 / DRAWINGS

Read the relationship

The drawings are original schematics. Circles stand for Earth and the Moon. A crew marker, orbit ring and a separate Eagle marker explain the four chapters. Landing callouts identify Columbia with Collins and Eagle with Armstrong and Aldrin.

Distances, sizes, positions, curves and transition durations are not to scale. The orange line is a narrative route, not an orbital calculation. The landing position and water strokes are symbolic. Movement shows a relationship between chapter states; it is not a historical flight simulation.

On a wide screen, the diagram changes as you reach a chapter. On a phone, each chapter has an in-flow scene. Eagle’s finite descent begins when the Landing figure is sufficiently visible; use “Replay Eagle’s descent” to inspect it again. Columbia remains in place. With reduced motion, the still crew relationship is shown. Reading uses normal scrolling, and chapter links go directly to their headings. The prose and source links remain available without JavaScript.

03 / YOUR NOTE

Keep your place

  1. Choose Keep this chapter beside the chapter you want to return to. It deliberately keeps that chapter and your current note. Scrolling never changes the kept checkpoint.
  2. Use a chapter’s Add a reading note link, or set Chapter for this note beside the field. That selection is the note’s target. Changing it updates the draft without replacing the kept checkpoint. Write in My reading note; a local draft is saved as you edit when browser storage works. Keep chapter & note deliberately keeps the selected chapter and note.
  3. Choose Download text to create a plain text file with the selected note chapter, your current note and the primary source links. It uses what is in the field at the time of download.

A draft contains your selected note chapter and latest local text; a kept checkpoint records your deliberate choice. On a return visit, a valid draft is restored first, with the checkpoint as a fallback. The “Return to my kept chapter” link uses the checkpoint.

Browser storage can be blocked, full, cleared or unavailable in a different browser. A failed write is reported beside the note, which remains usable. Download a copy before leaving if saving fails. An edited note that cannot be recovered triggers the browser’s ordinary leave-page warning. Clearing a note is an edit too. If the checkpoint is saved but draft recovery cannot be confirmed, keep the reader open and download the current note before leaving. Unsupported saved data is ignored rather than trusted.

Nothing is uploaded. The download is a file created on your device; it is not a submitted record or a cloud backup. The note is limited to 3,000 characters.
