Your first loop

  1. Choose a starting point. Weave crosses the paths of eight loops. Orbit spreads five loops farther apart. Ripple brings twelve loops around a shared center. Each uses the same model and controls.
  2. Set the motion. Elements changes the number of loops; Cycle changes the time for one complete repetition; Travel changes how far their centers move.
  3. Inspect a moment. Pause holds the visible position. Move Phase to scrub through the cycle. Scrubbing pauses playback so you can choose an exact frame.
  4. Keep the work. Save SVG creates the frame you see. Playback HTML keeps the settings, starting phase and a player in one file. Both exports pause the sketch first.

Four controls, one model

The loops vary in size and angle. Their centers follow a repeating path with twice as many vertical turns as horizontal turns. Travel scales that displacement; it is a relative design unit, not a physical measurement.

ControlRangeWhat changes
Elements3–12 whole loopsThe count and spacing of the family
Cycle1.0–6.0 secondsThe time for one complete loop, in tenths of a second
Travel0–100 whole unitsThe distance the centers wander from their shared origin
Phase0–100%The position inside one repetition; 0 and 100 show the same frame

Changing a setting keeps your current phase. Choosing a preset loads its starting settings and phase. The Weave, Orbit or Ripple name stays visible when those three settings match a preset; other combinations are called Your sketch.

A useful experiment: pause Weave at 25%, then move Travel from 60 to 0. The same loops gather around the center. Change only Cycle next: the held frame stays the same because Cycle controls speed.

Working copy and kept sketch

The working copy follows your edits in this browser. While playing, its phase is recorded periodically and again when the page becomes hidden or you leave. Reloading or returning from this guide recovers a valid working copy in a paused state.

Keep in this browser makes a separate checkpoint at the current phase and pauses the loop. After more edits, Recover kept sketch brings back that checkpoint. Reset current sketch asks before replacing your working copy with Weave; it leaves the separate checkpoint available.

Recovery belongs to this browser profile and this site address. It does not follow you to another device, private browsing session or different local server. PHASE checks the version, fields and bounds of recovered data before using it.

If storage is blocked, full or malformed, the current valid sketch remains usable. The page explains the recovery problem. Save playback HTML for a portable copy; it does not depend on browser storage. A failed save is never shown as a kept checkpoint.

Choose what to take

SVG / the frame

A 640 × 640 vector composition with its background, loop geometry and settings metadata. It uses no text fonts or linked assets. Open it in a browser or a compatible vector editor. It is a still image of the phase shown when you export.

Playback HTML / the loop

A standalone document with the exact model, settings and starting phase. It opens paused. Choose Play to watch the loop, Pause to hold it, or use its Phase slider to inspect another moment. It includes its own code and uses system interface fonts, so it needs no network connection.

These files are created locally. PHASE does not upload your sketch, send a server job or add analytics.

A still frame is useful too

All settings have labelled range and number controls. Use Tab to reach them, arrow keys for range changes, or type a number directly. The play button, presets, files and recovery controls are ordinary keyboard and touch controls.

A reduced-motion preference starts the sketch paused. If that preference changes while playing, PHASE pauses at its current position. You can still inspect the full cycle with Phase, export files, or deliberately choose Play.

Playback suspends when the artwork is offscreen or the browser tab is hidden, then continues from the held phase when it returns. Paused and suspended sketches do not keep scheduling animation frames. Normal page scrolling stays in your control.
