# PHASE notices

The PHASE interface, model, guide and vector artwork were created for the Begin motion transfer trial on 15 October 2026. No upstream website source, component code, screenshot, artwork or design recipe was imported.

## Local fonts

The website bundles unmodified Syne and DM Sans font binaries. Each family is used under its original SIL Open Font License 1.1; these fonts are not relicensed as PHASE interface code.

- Syne binary: `assets/fonts/syne.ttf`
- Full Syne notice: `assets/notices/syne-OFL.txt`
- DM Sans binary: `assets/fonts/dm-sans.ttf`
- Full DM Sans notice: `assets/notices/dm-sans-OFL.txt`
- Official source URLs and local hashes: `assets/FONT_SOURCES.json`
- Current-site provenance: `assets/PROVENANCE.json`

Only font assets were copied from the frozen local Begin pack. Exported SVG contains vector geometry and no fonts. Playback HTML uses system interface fonts and contains no embedded or remotely linked font assets.
