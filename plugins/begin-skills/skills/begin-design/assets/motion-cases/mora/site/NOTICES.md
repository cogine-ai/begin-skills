# MORA notices

MORA is a fictional consumer lamp brand created for the 15 October 2026 Begin motion transfer trial. The identity, English copy, original SVG lamp drawing, mark, HTML, CSS and JavaScript in this unit are original trial material. Catalogue facts come from the supplied MORA task brief. The drawing is schematic, not to scale, and supplies no photometric or manufacturing proof.

This example creates a local configuration and a standalone HTML specification. It does not place or transmit an order, reserve stock, take payment, upload settings or run analytics. No certification, stock, delivery or warranty claim is supplied.
