04

Find your angle

Move the tilt slider from 15° to 65° in 5° steps. You can also focus the slider and use the arrow keys. The drawn arm pivots and its light pool follows the head.

Selections remain available while the drawing moves. If your device requests reduced motion, changes appear directly in their new position.

05

Keep the whole specification

  1. Set a whole quantity from 1 to 8. If a typed quantity is invalid, the last valid configuration and its export stay available.
  2. Read the full result. Check the selected parts, catalogue dimensions, unit price and total for that quantity.
  3. Choose “Keep HTML specification”. The actual download contains a standalone drawing and all selected details, including the fictional catalogue and no-order boundary.

The file needs no network or font download. It does not place or transmit an order, reserve stock or take payment. No certification, availability, delivery or warranty claim is supplied.

06

Return to the same light

The page tries to keep your latest valid configuration in browser storage and checks the saved value. If storage is blocked, full or unreadable, the current light and export remain usable. The configurator’s Local recovery note reports that result.

Internal guide, home and configuration links carry the valid settings too. Use those links to return with your selection when storage is unavailable. An HTML specification is the portable record to keep after closing the browser.
