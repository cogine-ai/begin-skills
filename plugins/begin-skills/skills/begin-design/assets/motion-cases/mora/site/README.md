# MORA local static site

Serve this complete directory over local HTTP. No package install or hosting account is required:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/` in a browser. Stop the foreground server with Ctrl+C.

- `index.html`: lamp study and arm comparison.
- `configure.html`: complete live configuration, local recovery and real HTML specification download.
- `guide.html`: practical configuration and recovery guide; internal links carry the current valid settings.

This unit is standalone. Keep `assets/`, both JavaScript modules, `styles.css`, font notices and provenance together. No analytics, account, order or server submission is present. The schematic is original, not to scale, and does not establish photometric performance or manufacturing properties.
