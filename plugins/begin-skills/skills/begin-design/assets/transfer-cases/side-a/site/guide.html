Make a two-session evening

Prepare Deep Listening and After Hours for Friday 13 November 2026. You will get 120 minutes of listening with 90 minutes between sessions.

Open these two sessions ↗

The link selects the two sessions. If you already kept a different itinerary, that saved version remains available. You can begin without clearing it.

  1. Check that Deep Listening and After Hours are selected, and that Night Shift is not.
  2. Select Prepare itinerary. The result should show this running order:
19:00–20:00Deep Listening60 minutes listening
20:00–21:30Between sessions90 minutes
21:30–22:30After Hours60 minutes listening

120 minutes listening90 minutes between · 19:00–22:30

Check the date and venue too: Friday 13 November 2026, The Cabinet Room. All times are the venue’s local time. This is a fictional evening; preparing a plan makes no booking.

Keep it and come back

  1. With the current prepared itinerary visible, select Keep in this browser. This replaces any earlier Side A itinerary kept in this browser.
  2. Check the message under the buttons: it should name Deep Listening + After Hours, with 120 minutes listening and 90 minutes between.
  3. Reload the page. The two checked sessions and prepared itinerary should return. You can also select Reload kept version to restore that snapshot while working.

A kept itinerary belongs to this browser on this device. A different browser or cleared website storage will not have that copy. If keeping fails, the current prepared itinerary remains available for a text download.

Hear the conflict, then correct it

  1. Keep the two-session selection and also select Night Shift.
  2. Read the conflict message: Deep Listening and Night Shift overlap from 19:30 to 20:00, for 30 minutes. All three choices remain checked so you can decide what to remove.
  3. The old result now says Selection changed — rebuild this itinerary. It still shows the last prepared schedule; keeping and downloading are unavailable while it is stale. Your kept version remains unchanged.
  4. Deselect Night Shift. Select Prepare itinerary again and check the original two-session times and totals.

If you remove Deep Listening instead, Night Shift + After Hours is compatible: 19:30–21:00, then 21:30–22:30, with 150 minutes listening and 30 minutes between. Keeping that new result would replace the old saved version.

If no session is selected, the planner asks you to choose at least one and prepares nothing. Your previous result and kept version remain available.

Take a text copy

With a current prepared itinerary visible, select Download text. Open side-a-13-nov-2026.txt from your downloads. It should contain the date, venue, both session times, the 90-minute gap, 120-minute listening total and 19:00–22:30 evening span.

The download contains the current prepared version. It does not change your kept version. If you change your choices first, prepare again before downloading.

Clear only when you want to start over

Clear itinerary removes the browser’s kept version and resets the current choices and result. Use it if you want an empty task. It does not delete a text file you already downloaded.

Local data reference & troubleshooting

What is kept

The browser stores one Side A itinerary under side-a.itinerary.v1. The record includes a format version, saving time and the prepared date, venue, sessions, listening total and gaps. The model checks stored values against the fixed programme before restoring them. It collects no name or contact details.

If recovery fails

If storage is blocked, you can still prepare and download a text copy. If a stored version is unreadable, the planner says so and leaves your current work available. Prepare and keep a new version to replace it, or clear it when you no longer need it.

Files and limits

The three pages and their assets run locally without an account. The itinerary model owns programme values and calculations; the interface script owns selection, keeping, recovery and download actions. The photograph’s source and context are in credits and notices.

This example has no cloud sync, reservations, tickets, payments, availability feed or sending action. Private browsing and local-file origins can treat storage differently; a text export is a separate portable copy.
