02

Keep and return

Choose Keep plan. The same goal, week and three sessions appear under Kept in this browser. Keeping replaces any previous kept plan at this site address.

Reload the page. With browser storage available, your kept plan and fields return. You can also choose Return to kept plan after changing fields; it restores both the fields and the prepared result.

If you leave with unfinished edits, reload recovers those fields too. The earlier kept plan stays available, and the prepared week is marked Inputs changed until you rebuild or return to the kept plan.

04

Take a copy

Build the values you want, then choose Export text or Export JSON. The download contains the exact current prepared goal, dates, start and end times, number of sessions and total minutes. Keeping is optional before export.

For the original sample, check that the copy says Learn Spanish, includes 16, 18 and 20 November 2026 at 18:00–18:45, and totals 135 minutes. The JSON includes the full date for each session and its end.

Export does not create calendar events. If you change any field after building, rebuild before taking another copy.

05

Reset or clean up

Reset draft returns the fields to the Spanish example and clears the prepared result. It leaves your kept plan available. Choose Build plan to prepare the example again, or Return to kept plan to recover stored work.

For optional cleanup, choose Forget kept plan. This removes the kept plan from this browser and leaves the current fields and prepared result in place. To clear all Cadence data, use the browser’s site-data controls for this address.

If storage is unavailable, Cadence tells you. You can still build and export; a kept plan cannot be promised until storage succeeds. An export gives you a separate copy.

Technical appendix

Cadence is a static fictional concept. The planner runs in the browser with no account, backend, AI service or calendar connection. Your chosen times are plain local times; the planner does not perform time-zone conversion.

Accepted fields
A nonempty goal of up to 80 characters; a real Monday date; one or more Monday–Friday choices; 30, 45 or 60 minutes; a 24-hour start time from 00:00 to 23:59.
Sessions crossing midnight
The result shows the ending date explicitly. A Friday session can end on Saturday. The weekly total counts the full duration of each selected session.
Storage and recovery
The key cadence-study-week-v1 holds the draft and one kept plan for the current browser and site address. Stored values are checked before recovery. Private browsing, storage restrictions or clearing site data can remove or prevent recovery.
Generated record
JSON records the goal, Monday date, weekdays, duration, start time, exact sessions, session count and total minutes. Export uses the prepared result after confirming it matches the current fields.

This guide’s exact fixture was checked with local model tests. Browser interaction and rendered review are recorded separately in this transfer study’s evidence.

Cadence is a fictional local study planner. Keep an export if you need a copy outside this browser.
