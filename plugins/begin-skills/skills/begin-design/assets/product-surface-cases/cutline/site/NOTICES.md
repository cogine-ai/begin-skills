# CUTLINE source and assets

Original fictional product, English copy, CSS, JavaScript and geometric frame illustrations created for this study. The sample cue wording and names were supplied in the task brief. No external photographs, video, transcription, endorsements or AI services are used.

Runtime typography: Oswald, Public Sans and IBM Plex Mono, all from the official google/fonts repository and distributed under SIL Open Font License 1.1. Full notices are in fonts/oswald-OFL.txt, fonts/publicsans-OFL.txt and fonts/ibmplexmono-OFL.txt. Official source URLs and file hashes are in FONT_SOURCES.json. These font licenses remain separate from the original site source.
