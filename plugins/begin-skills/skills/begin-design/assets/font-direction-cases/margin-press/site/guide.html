01 Choose your three books

Open the reading shelf. If it already contains open work, finish that work first. To start this exercise from an empty shelf, choose Reset open shelf. This removes the open selection, name, note and prepared list; a kept version remains available.

  1. Add The Other Side of the Weather, A Room Full of Borrowed Names and No One Calls After Midnight.
  2. Leave the other two books unselected.
  3. Set Shelf name to Summer crossings.
  4. In A note · optional, enter For the train and the late afternoon.

03 Keep, then make a change

  1. Choose Keep shelf. This deliberately stores this prepared version in the current browser. If a kept shelf already exists, this replaces it.
  2. Remove No One Calls After Midnight. The open selection becomes 2 books, 272 pages and 200 min.
  3. The earlier three-book list remains visible. Its status becomes Earlier selection; Keep shelf and Download .txt are disabled.

You can choose Prepare shelf again to replace the old preview with the changed selection. For this exercise, leave the earlier list in place and restore the kept version next.

04 Restore the kept shelf

  1. Choose Restore kept. It replaces the open selection, name, note and prepared list with the kept version.
  2. Check that all three original books are selected again: 384 pages and 280 min. The prepared list is Current.
  3. Reload the reading shelf page. Reloading clears the open work. A message says that a kept shelf is available.
  4. Choose Restore kept again. The three-book shelf and its note return.

Keeping belongs to this browser and website address. A different browser, address or cleared browser storage may not have the kept shelf. Download a text copy when you want a separate file.

Shelf reference

Choose books
Select at least one of the five editions. Page counts and reading minutes are fixed catalogue values.
Shelf name / note
A name needs 1–70 characters. A note is optional and accepts up to 240 characters. Leading and trailing spaces are removed when preparing.
Prepare shelf
Creates a current text result from the open selection. Invalid input preserves the earlier preview and shows a correction.
Keep shelf
Saves one current prepared list in this browser. It replaces the earlier kept version.
Restore kept
Replaces open work with the kept version and prepares that version. An unreadable kept version leaves open work intact.
Forget kept
Deletes only the kept browser version.
Reset open shelf
Clears the open selection, note and prepared result, and restores the default name. It leaves any kept version available.
When storage is unavailable
You can prepare and download. Keep, restore and forget need working browser storage.

The press and every book, author and translator are fictional. This tool records a reading intention; it does not provide a book, reserve stock, take payment or track actual reading.
