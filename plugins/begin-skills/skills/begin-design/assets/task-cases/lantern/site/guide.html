04 / Check and recover

Reload, then reset

  1. Reload in the same browser and site origin.

    If the storage note says Saved in this browser, event_1043 remains selected with the new Delivered result.

  2. Choose Reset samples.

    All four records return to their original values and order. The filter is All and event_1044 is selected.

  3. Choose Failed again.

    event_1043 is Failed, response 503, 0 ms, attempt 2. The exercise is ready to repeat.

Storage unavailable means changes last for the current page only; reload restores the originals. Reset replaces only Lantern’s saved sample state and preserves other website storage.

Limits & recovery / Browser local

Keep the sample boundary clear

This Sample stream needs no endpoint, credential, or account setup; no webhook is sent. The browser owns the exercise. When storage works, Lantern saves the records, filter, and selection on this site origin. Another browser, profile, port, or cleared storage can start fresh. There is no live stream, account, delivery queue, backend, or team synchronization.

The selected event vanished from the list.

After retry, it becomes Delivered and leaves a Failed or Retrying list. Its result stays open. Choose Show all events to see it in the stream. When you manually change filters, selection follows the visible records.

The saved result did not survive reload.

Read the storage note below the inspector. “Storage unavailable — changes last for this page only” means saving is not available. Complete the exercise on the current page; reload starts fresh. Cleared browser storage or a different site origin also starts fresh.

I need a clean starting point.

Choose Reset samples. It restores the four original records, All, and event_1044. If saved data is invalid, Lantern falls back to the originals and announces the recovery.

Can this retry contact my webhook receiver?

No. Simulate retry only changes the selected sample record in this browser. A real webhook service would require a separate integration outside this sample.
