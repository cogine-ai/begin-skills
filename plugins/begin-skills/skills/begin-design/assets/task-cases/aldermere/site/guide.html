Prepare a three-night stay

Open Plan a stay with JavaScript enabled. If you want a clean start, select Reset first: it immediately removes the saved enquiry from this browser.

  1. Set Arrival to 20 October 2026 and Departure to 23 October 2026.
  2. Choose 2 guests. You can leave A note about the stay empty.
  3. Under Review your stay, check both dates, the two guests, and the indicative nightly rate of USD 180.

  1. Select Prepare enquiry. The result receives focus and its label becomes Current. It repeats your dates and guests, shows 3 nights × USD 180 = USD 540, and includes the room’s access and breakfast details.

Preparation creates a summary on this page. It does not check availability, send a message, take payment, or confirm a reservation.

If a date is missing or departure is on or before arrival, a field error explains the correction. The first invalid field receives focus and your other values remain in place.

Keep the prepared enquiry

When the label is Current, select Save locally. A successful save says “Saved in this browser. Reload this page to restore your prepared enquiry.” Reload the same address in the same browser to restore the saved fields and current summary.

Saving a new enquiry replaces the previous saved enquiry. Storage belongs to this browser, device and site address. A different port, browser, device, private session or cleared site data may give you a different store.

Download summary creates a UTF-8 text file of the current prepared result. The file includes the estimate and booking limits. Keep it somewhere you control.

Change your plans

Editing a date, the guest count or the note makes the prepared result Stale — prepare again. The old result remains readable, while Save locally and Download summary are disabled. Review your new choices and select Prepare enquiry again, then save again to keep the change.

Returning a field to its earlier value still requires preparation again. Reloading restores the last saved enquiry, so unsaved edits do not replace it.

Reset removes the saved enquiry, clears both dates and the note, returns to two guests, and clears the prepared result. It takes effect immediately and has no undo. Focus returns to Arrival.

Saving reports a storage problem

The current summary remains available for this visit. Use Download summary to keep a text copy. Browser privacy settings or direct file access can prevent local storage.

A saved enquiry cannot be restored

The page opens with empty dates, two guests and no prepared result, then reports the problem. Select Reset to remove the unreadable record, or prepare and save a new enquiry.

Reset cannot remove the saved record

The page resets for this visit and reports that the old enquiry may return on reload. Clear this site’s stored data in browser settings to remove it.
