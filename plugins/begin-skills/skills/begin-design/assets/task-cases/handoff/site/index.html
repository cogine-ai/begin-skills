An original fictional instruction

Put the reader at the bench

This example assumes a fictional USB sensor with a ready light. The team must verify the device's actual behavior before publication.

Original note01 / setup
Connect the unit and wait until it is ready. If it doesn't work, reconnect it and try again.
↳

Which port? What means ready? When should the reader stop?

Proposed revision01 / setup

Connect the sensor

  1. Connect the sensor to your computer with the supplied USB cable.
  2. Wait up to 10 seconds for the status light to turn steady green.
  3. If the light stays off, reconnect the cable once. If it still stays off, stop and contact support.
What changed

The connection, ready state, retry limit, and stop condition are explicit. The product team still owns each technical fact.
