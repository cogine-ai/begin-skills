02 / Change the route

An earlier winner changes what follows

  1. Load the sample. In Quarterfinal 1, change North Coast Circuit’s score from 1 to 4.
  2. North Coast Circuit now advances. Both scores in Semifinal 1 and the final clear. Semifinal 2 keeps its 1:3 result.
  3. Enter a new Semifinal 1 result. Its winner becomes the first named finalist. Then enter the final again.
  4. Select Prepare round report to replace the previous prepared record with this new route.

A tie is unfinished

Change Quarterfinal 2 to 4:4. Neither team advances. Semifinal 1 waits for that match to have a winner. A score of zero is valid; an empty score means it has not been recorded.

Changing a score while keeping the same winner preserves later scores, because the opponents have not changed. Every valid edit still makes the previous prepared report stale until you prepare again.

03 / Make a readable record

Prepare, inspect, download

Select Prepare round report. The document immediately below shows all seven matches, their actual opponents, score, winner or unfinished status, and where the winner goes.

You can prepare a partly completed bracket. Unresolved feeder matches remain clearly named, and the champion is marked undecided. A tie does not pick a winner for you.

If a score is outside 0–9 or has a decimal, correct the field identified by your browser. Invalid input blocks preparation, keeping and downloading. Your last prepared record stays visible. A valid edit also keeps that old document visible with a stale label, so you can see what needs to be replaced.

Open Inspect the exact text record to read the same text that downloads. Select Download UTF-8 record to take gridshift-round-report.txt. Accented entrant names stay intact.

04 / Browser-local state

Choose what survives a reload

Keep in this browser stores one current, prepared record. Keeping another replaces it. Storage is local to this browser and site address. If storage is unavailable, the desk says the keep failed; you can still take a text copy.

Recover the kept record replaces your working scores with the last kept scores and rebuilds their report. Use it after an accidental edit or after starting fresh. The score desk does not recover automatically on reload; it opens with the sample and tells you if a kept record is available.

Start a fresh bracket clears the working scores and prepared report. Your kept record remains available. Load sample scores replaces working scores with the supplied example and also leaves the kept record alone.

Forget the kept record removes the browser’s stored copy. The current working scores and prepared report remain on screen. Once forgotten, that stored record cannot be recovered here.

The spectator page displays the kept snapshot when opened or reloaded. When no kept record exists, it displays the supplied sample and labels it. There is no network sync, live broadcast, account or backend. Share an exported file separately if someone else needs the record.
