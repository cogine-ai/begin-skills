Keep a clear handoff

Use the shared shelf to find the equipment. Record what changes hands, leave a condition note, then prepare a complete report for the next operator.

01

Read the shared shelf

The equipment desk opens with all six items. Available means an item can be lent or placed in maintenance. Out shows its member, due date and loan note. Maintenance means it is off the shelf until an inspection or repair outcome is recorded.

Select the full equipment name to open its handoff desk. C05, the Manfrotto 055 tripod, begins with Mara Ellery and is one day overdue. C02, the Sennheiser MKH 416 microphone, begins with Élise Renard and is due the next day.

The clock is deliberately simulated: 2026-10-15. A due date before that date is overdue; a due date on that date is due today. Every new event uses that same clock, even if your computer has a different date. Opening loan dates were not supplied and remain labelled as unknown.

02

Check out an available item

  1. Select an Available item, such as C01, Sony FX30 camera.
  2. At the handoff desk, choose Check out. Enter the Member’s full name.
  3. Enter a real Due date in YYYY-MM-DD form, on or after 2026-10-15. For example, 2026-10-16 is valid. 2026-02-30 is not a real date.
  4. Add an optional Loan note, such as which accessories travelled with it, then press Check out.

The item changes to Out. Its member, due date, loan note and simulated loan date are recorded in a new custody event. The inventory summary updates immediately. An item already out or in maintenance cannot be checked out.

If a field is invalid, the action does not change inventory or add an event. Correct the field or use Cancel fields. Changing the selected item or action asks before discarding typed fields.

03

Record the complete return

Select the item that is Out. Its handoff desk shows the full member name and due date, so you can confirm which loan is ending. Enter a Condition at return note, then press Record return.

The item becomes Available and the condition note appears on the shelf. The return event keeps the original member name, original due date, original loan date if known, the simulated return date, and your full condition note. Earlier checkout or snapshot events remain in the history.

A blank condition note blocks the return. If the item needs repair, record its return first, then set maintenance. The maintenance action cannot remove an active borrower.

04

Take kit off the shelf, then restore it

For an Available item, choose Set maintenance, enter a Maintenance reason, and press Set maintenance. Its state becomes Maintenance and a full event is added.

C03, Aputure 300d II light, starts in maintenance with the note “Power cable inspection”. Select it, enter the Inspection or repair outcome, and press Restore availability when you want to make it Available. The outcome becomes its current note and a restore event joins its history.

Both actions require a nonblank note. The desk presents only actions the selected item’s current state supports.

05

Prepare the whole handoff record

In Make the handoff report, edit the Report title and optional Operator note. Complete or cancel any open action, then press Prepare complete report.

The prepared report includes all six equipment records, even when a status has no items, plus every original snapshot event and every added event. Each record includes its full name, state, member, loan date, due date and note. Every event includes its full equipment name, date, state change, member, loan date, due date and note. Unknown opening dates are explicitly labelled.

Valid edits make an earlier report stale. Invalid fields leave the last prepared report visible for inspection and block preparation, keeping and downloading. Fix the fields, finish or cancel the action, and prepare again. A report with an empty title cannot be prepared.

Open Inspect the exact download text to read the full text. Download exact text ↓ downloads that exact prepared content as UTF-8, with its names and accents intact. The filename is checkout-equipment-report-2026-10-15.txt. The text has ordinary LF line breaks, a final newline and no added byte-order mark.

06

Keep a copy, then recover deliberately

Keep this report & desk is available only for a valid current prepared report. It saves that report, the complete six-item inventory, the event history, report title and operator note to this browser. It replaces the previous kept copy.

  1. Use Reset working desk to return the current work to the six opening fixtures. Confirm the reset. The kept copy stays available.
  2. Use Recover kept copy to replace the current working desk and report with the saved copy. Confirm the replacement. After a page reload, you must choose recovery explicitly.
  3. Use Forget kept copy to delete the saved copy. Confirm the deletion. Current work and downloaded files remain.

Typing and recording actions do not save automatically. Reloading the equipment desk returns to the opening fixtures until you recover a kept copy. If browser storage is unavailable, keeping reports an error; you can still use the desk and download text. An unreadable or incompatible saved copy is rejected without replacing current work.

This is fictional, local demonstration data. There is no shared backend, real member account, email, payment or live equipment record. Another browser or device will not see this copy. Avoid entering private real-world member information.

07

Try a full handoff

Start at the equipment desk. Select C01, enter Jules Navarro, due date 2026-10-18, and loan note Battery and strap included. Check it out. Select it again, enter Returned clean; battery and strap present, and record its return.

Set C01 to maintenance with Inspect strap attachment. Restore it with Attachment checked; ready to lend. Prepare the complete report. It should have all six records and 10 custody events: six original snapshots plus your four added actions. Jules Navarro appears in both the checkout and return events.

Keep that report and desk. Reset the working desk, then recover the kept copy. The ten events should return. Finally, forget the kept copy if you want to remove this practice session from browser storage. The working report stays visible.
