# Kiln Notes asset notices

This fictional ceramics journal, its English writing, HTML, CSS, local worksheet model, worksheet adapter and material drawings were created as original trial material on 11 October 2026. The drawings represent imagined color studies, not measured firing results.

## Local fonts

All font binaries are unchanged copies from the frozen Begin dev.12 pack supplied to this trial. Complete notices remain beside the binaries. No font is subsetted, renamed internally or converted.

- **Fraunces**: original `fraunces.ttf` from `begin-design/assets/typography-cases/side-a/site/fonts/`. Copyright and full SIL Open Font License 1.1 are in [fraunces-OFL.txt](fonts/fraunces-OFL.txt). The supplied source identity is preserved in [fraunces-source.json](fonts/fraunces-source.json); its unused body-family entry describes that source case, not this site.
- **Alegreya**: original Roman and italic binaries from `begin-design/assets/type-transfer-cases/sunday-table/site/fonts/`. Copyright and full SIL Open Font License 1.1 are in [alegreya-OFL.txt](fonts/alegreya-OFL.txt). Supplied metadata is preserved in `fonts/alegreya-METADATA.pb`.
- **Karla**: original Roman variable binary from `begin-design/assets/type-transfer-cases/sunday-table/site/fonts/`. Copyright and full SIL Open Font License 1.1 are in [karla-OFL.txt](fonts/karla-OFL.txt). Supplied metadata is preserved in `fonts/karla-METADATA.pb`.

The Sunday Table source list is retained in [sunday-font-sources.json](fonts/sunday-font-sources.json). Exact trial input paths, hashes and adaptations are recorded in the raw study’s `INPUT_USE.json`, which is excluded from this portable site.

No photographs, remote fonts, external scripts or external artwork are used.
