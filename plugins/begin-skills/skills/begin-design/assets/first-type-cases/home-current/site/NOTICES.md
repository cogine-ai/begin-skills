# Home Current asset notices

Home Current is a fictional household energy worksheet made for this isolated Begin dev.12 first-output study on 11 October 2026. Its English writing, HTML, CSS, local calculation and snapshot scripts, plug mark and room heater drawing are original work created for this brief. The illustration is a conceptual appliance drawing.

## Design method

The frozen Begin dev.12 begin-design Skill, its relevant method references, and the packaged Relay and Sunday Table desktop/phone openings supplied the operative design method. Their complete source was inspected for the numeric conditions and household worksheet relationships. Home Current uses original composition, writing, drawing, styles and scripts. No reference artwork or code was copied.

## Local behavior

There is no backend, account, external transmission, tariff service, utility integration, energy advice or payment. Keeping saves one validated prepared snapshot to this browser's home-current.energy-sheet.v1 localStorage key. The download is a local plain-text file. Reset affects only this worksheet key.
