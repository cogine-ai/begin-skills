02 · Know which version you have

Current on screen, kept for later

Prepared · Current means the budget matches the inputs you last prepared. Select Keep in this browser to explicitly save that snapshot, including the performance, counts and note. Keeping replaces the previous kept copy.

Reload the worksheet to recover the kept inputs and budget together. Unkept changes disappear on reload. Keeping uses this browser’s local storage; another browser or device has its own separate copy.

Change either count, the performance or the note. The previous budget remains visible with Stale · Prepare again. Keeping and downloading stay disabled until you prepare the revised inputs.

For example, change the Saturday example to 3 adults and 1 student. Prepare again to see 4 tickets and USD66. The kept USD48 copy stays separate until you explicitly replace it.

Changing an input back to its old value still requires preparation. The result always represents a deliberate preparation.

03 · Keep the useful work

Correct an entry

Try 2.5 in Adults and prepare. The editable value stays in the field, and a message asks for a whole number from 0 to 8. An earlier prepared budget stays visible and stale.

Change it to 2 and prepare again. The error clears and your budget becomes current. Each ticket count can be 0–8, but together they must make a party of 1–8.

0 adults, 0 students
Add at least one ticket.
8 adults, 1 student
Reduce the combined party to eight or fewer.
Blank, words or a fraction
Enter a whole count such as 0, 1 or 2.
A long note
Keep it to 300 characters or fewer.

04 · Return to a useful point

Recover a copy or start again

Restore kept version returns the last kept show, counts, note and budget. It replaces your current draft edits. Use it to return from an experiment to the budget you meant to keep.

Reset worksheet empties the prepared result and note, then selects The Borrowed Moon with 1 adult and 0 students. Your kept copy is still available to restore. Reset is optional when starting the example.

To remove the stored copy, open Remove the kept copy and select Forget kept budget. That removes only this worksheet’s storage entry. It leaves the current screen and any downloaded files alone.

If browser storage is blocked, the worksheet will tell you that keeping or recovery failed. You can still prepare a budget and download a current text copy. A damaged saved record is not loaded as a valid budget.

05 · A copy beyond the browser

Take the budget as text

When your budget is current, select Download text. Open the resulting .txt file. Compare the performance and date first, then the counts, two line totals, party size, exact total and visitor note.

Performance: A Very Small Revolution
Date: Saturday 24 October
Time: 16:00
Adults: 2 x USD18 = USD36
Students: 1 x USD12 = USD12
Party size: 3 tickets
Total: USD48

The download uses the current prepared budget on screen. If you have edited an input, prepare again before downloading. Downloading does not keep a copy in local storage; use Keep in this browser for that.

The calculation is adults × USD18 plus students × USD12. No fees, tax, discounts or live box-office rules are inferred.
