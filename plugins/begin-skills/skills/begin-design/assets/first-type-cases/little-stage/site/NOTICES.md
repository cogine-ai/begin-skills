# Little Stage notices

Little Stage is a fictional neighborhood theatre. Its three October programme entries and ticket rates come from the supplied Little Stage brief. Dates, prices and the theatre itself are illustrative. The site has no reservation, checkout, account, availability service, backend or external transmission.

The website's English writing, hand-authored SVG theatre illustration and mark, HTML, CSS, JavaScript and fixtures were created for this isolated Begin dev.12 first-output trial on 11 October 2026. Design relationships were studied in the frozen Begin pack. The exact consumed inputs and transferred decisions are recorded in the raw study’s `INPUT_USE.json` and `METHOD.md` records, which are excluded from this portable site.

## Local behavior

The worksheet's explicit Keep action writes one prepared budget under `little-stage.ticket-budget.v1` in localStorage. Reload or Restore recovers that kept copy. Reset changes the working worksheet while retaining the kept copy. Forget removes only that key. Download creates a plain-text file from the current preparation. The application makes no network requests; the fonts and artwork are local.

Paths inside the preserved PACKAGED_NOTICES.md are historical source-case locations. This notice names the complete licenses and source records present in this site.
