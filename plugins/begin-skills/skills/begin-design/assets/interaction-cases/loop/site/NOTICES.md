# LOOP source and font notices

LOOP is a fictional neighbourhood refill shop for an independent local design trial. The six product names, price bases and container requirements were supplied in the LOOP task brief. No live shop, stock, checkout, order transmission, collection booking or payment service is represented.

All page writing, HTML, CSS, JavaScript and six SVG container illustrations are original to this task. The illustrations depict invented refill containers; no photograph, product package, upstream component or external implementation was copied. There are no runtime network services, remote fonts, third-party scripts or package dependencies.
