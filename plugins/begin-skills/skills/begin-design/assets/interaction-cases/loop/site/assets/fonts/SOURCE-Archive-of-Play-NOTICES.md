# Source and font notices

Archive of Play is a fictional archive. All six game names, rules, dates, player ranges and estimated durations were supplied by the controlled task brief. Site writing, interaction implementation and six SVG object studies were created for this draft. The drawings are original invented representations, not historical object photography.

The project began through the frozen Begin dev.15 editorial creation helper. The source scaffold and guidance were replaced for this task. Its internal development candidate status grants no new public redistribution license for Begin-authored or newly project-authored material. No public release was made.
