01

Find a record

Open the desk and search by ID, species or location. Try T-1042, lime or Lock Lane. Status buttons narrow the current search. Their counts describe the search results; the three totals above the desk always describe all nine saved records.

Select a row to inspect that tree. On a phone, selection moves to its inspection sheet. Use Records to return or Inspect T-1042 to jump to the current selection. Every row is a keyboard button.

A selected record remains selected when a filter hides its row. Clear the search and filters to see it again. An empty result includes the same clear action.

02

Read the saved facts

The sheet connects the tree's ID, full species and location with its last-inspected date, status and saved note. A local edit time appears separately. Editing a note does not change the supplied inspection date.

When two trees share a named road, the comparison keeps the other record’s saved date and note beside your current sheet. For example, T-1042 and T-1043 are both on Pearson Road. Other places show a small quarter index. This sample has no coordinates, distances or mapped route.

03

Edit with an explicit finish

  1. Choose Edit inspection on the current sheet.
  2. Select Due, Watch or Complete and write the note. Notes can contain up to 4,000 characters; longer paragraphs expand into ordinary page scrolling.
  3. Choose Save changes to update the saved record. Its collection row, badge and all-register totals update together.

Cancel discards this tree's draft and returns to its last saved note and status. Switching to another tree keeps the unsaved draft attached to its original ID. Reopening it resumes editing.

04

Resume after a reload

With device storage available, the workspace keeps saved notes, statuses, unsaved drafts, search, filter and selected ID in this browser. A save is reported as saved on this device only after the page writes the data and reads the same data back.

If the browser denies storage or a write fails, the workspace says Session only. Your current work stays in the open page. Reloading, leaving the page or closing it can lose that session. Use Download backup before leaving, or try Retry device storage.

This sample does not sync across browsers, devices, people or simultaneous tabs. Avoid editing the same local workspace in two tabs.

05

Recover a workspace

Use Download backup to request a JSON copy containing all saved local records, drafts and your current selection. Check that the download reached your device. Restore backup accepts a valid CANOPY JSON file up to 512 KiB and replaces the current workspace.

Unrecognized or damaged stored data is rejected before rendering. The page opens the original sample records and leaves that stored copy untouched. You can keep working for the session, download it, or deliberately reset the workspace. Invalid imported files leave current work unchanged.

Start again with sample records requires a second, inline choice before replacing all saved notes, statuses and drafts. Download a backup first if you need them.
