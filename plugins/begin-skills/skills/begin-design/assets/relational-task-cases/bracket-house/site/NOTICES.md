# Bracket House notices

The brand, words, bracket mark, HTML, CSS, JavaScript and fictional event example are original teaching material created for this case. No photo or external artwork is used.

Unchanged Teko and Public Sans font bytes are retrieved from the official Google Fonts repository. Complete SIL Open Font License files are retained locally alongside the fonts. Exact URLs, byte lengths and SHA-256 hashes for every font and notice are in `FONT_SOURCES.json`.

- Teko: `fonts/Teko-Variable.ttf`, full notice `fonts/Teko-OFL.txt`.
- Public Sans: `fonts/PublicSans-Variable.ttf`, full notice `fonts/PublicSans-OFL.txt`.

This static fictional site has no server, transmission, account, purchase, registration or telemetry. Browser storage and exact download are local capabilities subject to browser policy.
