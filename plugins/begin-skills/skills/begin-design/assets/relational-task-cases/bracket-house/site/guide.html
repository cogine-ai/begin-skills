MAKE ONE COMPLETE RESULT

Record a night from the first four matches to its champion. You need an event name and a winner for every match. This guide uses the fictional eight-team bracket supplied on the working page.

  1. Open The bracket. If this browser has a valid kept copy, the page restores it when it opens.
  2. Enter an Event or result name. Add an optional Note to keep a detail with the result.
  3. Choose a winner for each quarterfinal: Q1, Q2, Q3 and Q4. Select the winning team name.
  4. Choose S1 from the winners of Q1 and Q2. Choose S2 from the winners of Q3 and Q4.
  5. Choose F1 from the winners of S1 and S2. The counter should read 7 / 7 matches decided.
  6. Choose Prepare bracket. Read the event name, champion, all seven full pairings and winners, and your note in The prepared result.

Expected result: “Prepared from current choices” appears beside the result. Download and keep actions become available. Preparation alone keeps work only on the current page.

THE FIELDS AND RULES

Event or result name
Required. Use at most 80 characters. A name made only of spaces is invalid. Spaces at the start and end are removed in the prepared result; the original typed input is kept for recovery.
Note
Optional. Use at most 400 characters. Line breaks are allowed. Spaces at the start and end are removed in the prepared result. An empty note exports as (No note).
Quarterfinals
The eight teams and four first-round pairings are fixed. Each winner must be one of that match’s two named teams.
Semifinals
S1 uses the winners of Q1 and Q2. S2 uses the winners of Q3 and Q4. Both upstream results are needed before either semifinal can be selected.
Final and champion
F1 uses the winners of S1 and S2. The F1 winner becomes the champion. The champion is calculated from the final choice.
Preparation
All seven choices must be valid and the event name must be present. Invalid preparation lists the affected fields or matches. It preserves the earlier result, if one exists.

Only the actual participants appear as winner controls. Typing a different team into the event name or note cannot add a participant to the tournament.

CHANGE A WINNER

Any edit to a name, note or winner marks an earlier prepared result Stale — prepare again. The earlier output stays visible, and Download exact text and Keep in this browser are disabled. Returning a field to its old value still requires preparation.

An upstream winner change also clears the choices that depend on that match. A quarterfinal can clear a semifinal and the final. A semifinal can clear the final. This avoids carrying a decision into a different pairing.

  1. Prepare the warehouse example.
  2. In Q1, choose Black Kite Assembly.
  3. Check that S1 and F1 have no chosen winner. S1 now pairs Black Kite Assembly with Élan Arcade. F1 waits for S1. The counter reads 5 / 7.
  4. The earlier prepared example still shows Northbank Afterhours in S1 and Élan Arcade as champion. Its stale label explains that it belongs to the earlier choices.
  5. Choose the new S1 winner, then the F1 winner. Choose Prepare bracket to replace the earlier result with the current valid record.

Invalid input exercise: after preparing a result, clear the event name and choose Prepare bracket. The page asks for a name. The earlier result stays stale and cannot be kept or downloaded. Enter a name, finish any missing winners, then prepare again.

KEEP, RECOVER AND CLEAR

The current inputs, a prepared result and a deliberately kept browser copy have different jobs. Work is never kept automatically when you type. Keeping stores the exact typed inputs and the complete prepared result in this browser’s local storage.

  1. Prepare a valid complete result. Choose Keep in this browser.
  2. Check the browser-copy message for the kept event name. A successful keep replaces any earlier kept copy.
  3. After edits or a reset, choose Recover kept work to replace current inputs and output with that exact kept copy. Recovery validates the saved record before replacing current work.
  4. Reloading the same page also restores a valid deliberately kept copy. Edits made after keeping are replaced by the kept version on reload.
Reset current work
Clears the current event name, note, winners and prepared output. It preserves the kept browser copy. Use Recover kept work to restore that copy.
Forget kept copy
Removes only the deliberately kept copy from this browser. Current inputs and prepared output remain on the page. A later reload starts empty unless you keep again.
No kept copy
Recovery explains that there is no copy and leaves current work unchanged. Prepare and keep a result to create one.
Corrupt kept copy
Recovery explains the invalid record and leaves current work unchanged. On reload, the page starts empty. Use Forget kept copy to remove the unusable saved record, then keep a valid result.
Denied storage
The page explains that reading, writing or clearing the browser copy failed. A failed operation does not claim success. Current work remains usable; download exact text while the prepared result is current.

Use the same browser profile and page address for recovery. Private browsing, browser settings, clearing site data and local-file storage policies can affect whether a copy is available. The text download is the portable record; it cannot be imported back into this demo.

TAKE THE EXACT TEXT

  1. Prepare the current valid bracket.
  2. Open Inspect the exact text if you want to read the export before downloading.
  3. Choose Download exact text. The browser is asked to download a UTF-8 .txt file named from your event or result name.
  4. Open the downloaded file and check its event name, four quarterfinals, two semifinals, final, champion and note. Each match includes its ID, two full participant names, winner, source relationship and destination.

The download uses the prepared snapshot’s exact text, including its final newline. Line wrapping in the on-page text is a reading aid and does not change the file. A download request does not prove where your browser saved the file; check your browser’s downloads.

The download does not create a kept browser copy. A kept browser copy does not create a downloaded file. Choose each action when you need its result.

LOCAL RESULTS, CLEAR LIMITS

Bracket House is an original fictional teaching example. It records this fixed eight-team tournament in the current browser. It has no server, data transmission, account, real registration, purchase or telemetry.

There are no scores, draws, reseeding, third-place match, extra teams or shared live updates. Only a winning team is recorded for each match. The site does not independently verify a match outcome. Anyone viewing the same computer and browser profile may be able to recover its kept copy.

A later match is waiting

Finish both source matches named beside it. A semifinal needs its two quarterfinal winners; the final needs its two semifinal winners.

A prepared result is stale

Complete the current choices and enter a valid name. Choose Prepare bracket again. Keeping and downloading are available only for the current prepared record.

My work disappeared on reload

Only a deliberately kept copy is restored. Check the browser-copy message. Try Recover kept work in the same browser profile and at the same page address. If no copy is available, use a downloaded text file as your record and re-enter its choices.

Winner controls do not appear

The working page needs JavaScript. Allow it in your browser and reload the page. The home and this guide remain readable without it. Reload restores only a valid kept copy.
