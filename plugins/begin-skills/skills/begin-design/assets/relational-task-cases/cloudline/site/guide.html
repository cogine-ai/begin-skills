Use the right kind of value

Cloudline reads one fixed week: 1–7 October 2026. The dates cannot be changed. You can change the title, note, daily values and comparison threshold.

Report title
Required text, at most 80 characters. A title containing only spaces is invalid. The prepared report uses the title you enter.
Observation note
Optional text, at most 400 characters. The report and export include your whole note. An empty note is shown as “No note supplied.”
Daily rainfall
Seven required readings in millimetres (mm), one per date. Each value must be nonnegative, at most 200.0 mm, and have at most one decimal place. For example, 0, 2.4 and 200.0 are valid. A blank field, −1 or 1.23 is invalid. Do not use commas, units, exponent notation or a decimal point without a following digit in the field.
Comparison threshold
A required value in mm, with the same numeric rules as a daily reading. It starts at 5.0 mm. It is your chosen comparison line, rather than a measured observation. Only readings strictly above it are counted. A reading equal to it is excluded.

The total is the sum of all seven readings. The mean is the total divided by seven, rounded to two decimal places. The maximum is the largest daily value, with every tied date listed. If all readings are zero, all seven dates are tied for the maximum.

A different threshold changes the above-threshold count. It does not change the readings, total, mean or maximum. Values appear in the report and export with one decimal place; the mean has two.

Change a day, then prepare again

With the example analysis prepared, change 6 October 2026 from 0.0 to 2.4. The earlier report remains visible and is labeled Earlier analysis · stale. Keep and download are disabled. Choose Prepare analysis to replace it with the valid current analysis.

The new total is 38.0 mm and the new mean is 5.43 mm/day. The maximum remains 14.4 mm on 4 October 2026. The count remains 3 days strictly above 5.0 mm.

Now change 6 October to −1 or 1.23 and choose Prepare analysis. The field is marked invalid, and the earlier report remains intact and stale. Its keep and download actions stay disabled. An empty daily reading is also invalid; Cloudline does not turn it into zero.

Correct the reading to 2.4 and prepare again. Returning a field to its previous value still requires a new preparation. This makes it clear which inputs produced the visible report. The same rule applies when you change only the title, note or threshold.

Loading the example changes all current inputs; it does not prepare them. Preparation uses the values currently in the fields, without sending them anywhere.

Keep only the work you intend to return to

Current inputs and their prepared analysis exist on this open page. A kept copy is separate. It includes the exact inputs and prepared output you deliberately chose to retain in this browser.

Keep in this browser
Available only after valid preparation, while the report is current. Choose it to write or replace the one kept Cloudline copy. Wait for the message confirming it was kept. Later edits do not update that copy.
Recover kept work
Replaces the current inputs and output with the exact kept record. Use it when you want to return to that version. Loading this page again also automatically restores the kept record. Unkept edits are lost on reload.
Reset current work
Clears the current title, note, seven readings and prepared output. The comparison threshold returns to 5.0 mm. A kept copy remains available; choose Recover kept work to bring it back.
Forget kept copy
Removes only the copy in browser storage. The current inputs and visible prepared analysis stay as they are. Reloading after a successful forget starts a blank record unless you keep a new copy.

If there is no kept copy, recovery explains that and leaves current work unchanged. If a copy is corrupt or incomplete, Cloudline rejects it and leaves current work unchanged. Forget can remove that corrupt stored copy.

To check your kept version: prepare the example, keep it, change one field, then recover. The example inputs and exact prepared report should return. Reset and recover demonstrate the same preserved copy.

Take the complete report with you

After a valid preparation, choose Download exact text. The browser receives a file named cloudline-analysis.txt. Your browser controls its save location and may ask where to put it.

The file is UTF-8 plain text with a final newline. It includes your title, fixed observation period, every dated reading, chosen threshold, complete note and summary. It is the same text shown under Inspect exact export text. The visual report arranges those same facts for reading.

A download does not keep a browser copy. Keeping a copy does not download a file. Editing makes the earlier report stale and blocks both actions until the current inputs are prepared successfully.

Know the limits of a small record

These observations are original fictional teaching material. Cloudline is an educational report and measurement exercise. It supplies no real weather claim, forecast, flood warning or safety advice.

All calculations and browser-copy operations run locally. There is no account, server processing, transmission of entered values, purchase, booking or telemetry. Local fonts are bundled with the site. Do not enter information you would be uncomfortable leaving in this browser on a shared device.

Browser storage can be denied, full, cleared or unavailable in a private session. If keeping fails, Cloudline says so and preserves current work; a valid exact download is still available. If recovery or forgetting is denied, the message describes that failure. It does not claim a copy was recovered or removed.

A kept copy belongs to this browser and this site's storage location. It does not move to another device or browser. Clearing site data can remove it. Use the exact text download when you need a separate file, and check that your browser saved it.
