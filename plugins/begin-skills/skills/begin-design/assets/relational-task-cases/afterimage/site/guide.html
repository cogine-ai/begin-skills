Make your first sheet

If there is current work you want to retain, prepare and download it before loading the example. Load example replaces the current inputs. It preserves any earlier prepared result as stale and leaves the kept browser copy alone.

  1. Open the cue-sheet page and choose Load example.

    The project becomes First light. Three cue rows are filled. Loading alone does not prepare a new result.

  2. Choose Prepare cue sheet.

    The project name, note, full cue titles, categories, start/end times and cue notes appear together beneath the action. The state says Prepared from current inputs.

  3. Check the three durations and totals.

    A01 is 18 seconds, A02 is 24 seconds, and A03 is 33 seconds. Occupied time and project span are both 75 seconds; gaps between cues are 0 seconds.

  4. Choose Download exact text to request a file, or Keep in this browser to retain one local copy.

    The downloaded file and kept browser copy are separate. Read the copy operations before replacing or removing a kept copy.

You have a prepared sheet with all three cues. Preparing is the check that enables keep and download; entering valid-looking times alone is not enough.

Try a correction and a gap

Start with the prepared example. An edit keeps the earlier output visible and changes its state to Earlier preparation · inputs changed. Keep and download are disabled until you prepare valid current inputs.

An invalid end

  1. Change A02 End from 00:42 to 00:17. Leave A02 Start at 00:18.
  2. Choose Prepare cue sheet.

    Preparation is blocked because A02 ends before it starts. The error links to A02 End. Your input stays at 00:17 so you can correct it; the earlier 75-second output remains visible and stale. Keep/download remain disabled.

A valid two-second gap

  1. Restore A02 End to 00:42, then change A02 Start to 00:20.
  2. Choose Prepare cue sheet.

    A01 still lasts 18 seconds. A02 now lasts 22 seconds. A03 still lasts 33 seconds. The prepared output is current again.

Occupied time becomes 73 seconds. Project span remains 75 seconds. The two-second gap is between A01 End 00:18 and A02 Start 00:20.

The tool follows row order. It does not sort cues or shift later cues after you edit a time. Restore A02 Start to 00:18 and prepare again to return to the original totals, or load the complete example and prepare it.

Fields and timing rules

Project name
Required. Up to 80 characters. Use a film or scene name. Empty or whitespace-only names are rejected. This is a single-line field.
Project note
Optional. Up to 400 characters. This note applies to the complete scene. Multiple lines are allowed. An empty note is shown as not supplied and exported as (none).
Three cue titles
Each title is required and can contain up to 100 characters. Empty or whitespace-only titles are rejected. Titles stay on one line while editing; the complete title wraps in the prepared sheet and export. Accents and punctuation are retained.
Category
Choose Atmosphere, Foley or Music for each cue. The initial row defaults are Atmosphere, Foley and Music; you may change them. A category labels the cue and does not change the timing calculation.
Start and End
Required for all three cues. Use exactly mm:ss: two minute digits, a colon and two second digits. Both pairs must be 00–59, so the range is 00:00–59:59. Fractions, frames, negative values, 0:18, 00:60 and 60:00 are invalid.
Cue note
Optional for each cue. Up to 300 characters. Describe the sound, its relationship to dialogue and the intended entrance or exit. Multiple lines are allowed. Empty notes are shown as not supplied and exported as (none).

Order and duration

Every End must be strictly later than its own Start. A02 Start must be at or after A01 End. A03 Start must be at or after A02 End. Adjacent cues may touch; gaps are allowed. This three-row tool rejects overlapping cues.

A cue’s duration is End minus Start, in whole seconds. Occupied time is the sum of the three durations. Project span is the time from A01 Start to A03 End. Span includes gaps between cues and excludes time before A01. Gaps between cues is span minus occupied time.

Small row durations update while you edit valid start/end pairs. They are timing aids, not a prepared sheet or proof that all rows pass the ordering rules. Use Prepare cue sheet to validate the complete project.

Keep, recover and clear work

The current inputs and prepared sheet live in the page. A kept copy is a separate local record for this browser and site. The tool restores that kept copy when you reload the cue-sheet page.

Keep in this browser

Available only after valid preparation of current inputs. It replaces the one kept copy with all current inputs and the prepared output. Keeping does not create a downloaded file. Wait for the kept confirmation; denied storage is reported as a failure.

Recover kept work

Replaces the current inputs and output with the kept copy exactly. Any current edits disappear. If no copy exists, storage is denied, or the copy is corrupt, current work remains unchanged and the message explains the problem.

Reset current work

Clears the current project fields, cue titles, times, notes and output. It restores the default categories. It preserves the kept browser copy. Recover or reload the cue-sheet page to bring back that copy.

Forget kept copy

Removes only the browser’s kept copy. Current inputs and output remain in the page. After forgetting, reloading has no kept work to restore. To clear both kinds of work, forget the copy and then reset current work.

Check a recovery

  1. Load and prepare the original example, then choose Keep in this browser. Check the confirmation.
  2. Change a cue note without keeping it. The earlier sheet becomes stale.
  3. Choose Recover kept work.

    The original note and the 75-second prepared sheet return. The state is current and the keep/download controls are enabled.

  4. Choose Reset current work, then Recover kept work again.

    The original inputs and output return because reset preserved the copy. Reloading the cue-sheet page restores the same copy.

Keeping is intentional: edits and preparation do not automatically replace the kept copy. An unkept edit can be lost on navigation or reload. A download remains a separate file after either reset or forget.

Download exact text

Prepare valid current inputs, then choose Download exact text. The browser receives afterimage-cue-sheet.txt as UTF-8 plain text with a trailing newline. Check the browser’s download list to confirm the file arrived.

The file includes the complete project name and note; A01, A02 and A03 full titles, categories, starts, ends, durations and notes; occupied time, project span with its start/end, and gaps between cues. The accent in Écho and supplied punctuation are retained.

Use Inspect the exact text export beneath the prepared sheet to read the same text before downloading. Its content refers to that prepared sheet. After an edit it remains the earlier text and is visibly stale; the download button is disabled. There is no text-file import. To reopen editable work, use the browser copy or enter the fields again.

When something needs attention

Preparation is blocked

Read the correction summary and follow its field link. Fix the named field without resetting. All entered input and earlier output are preserved. Prepare again after the correction.

Keep or download is disabled

There is no current prepared sheet, or input has changed since preparation. Choose Prepare cue sheet. Valid input must be explicitly prepared before either control is enabled.

The kept copy is unreadable

The tool rejects unreadable data, an unsupported copy format, invalid kept input or a result that does not match that input. It keeps your current work. Download a current prepared sheet if needed, then use Forget kept copy and keep a newly prepared sheet.

The browser denies storage

The tool reports that it could not read, keep or remove the copy. Private modes, browser policy or site settings can affect local storage. Current work stays in the page. Download exact text for a file; browser storage is not guaranteed.

A reload has no copy

Only intentionally kept work can return. Storage is tied to the browser, profile and site origin; another browser or address may have a different copy. Browser data clearing can remove it. Unkept current work is not automatically recovered.

The file is missing

Check the browser’s download list and file-location settings. The page can request the download but cannot confirm a file was written. Keep or download again while the sheet is still current.

Local work, clear limits

Afterimage is a fictional sound studio. The station illustration and cue sequence are invented teaching examples. No playable audio is provided.

The sheet helps you prepare a discussion; it does not edit or mix sound. It supports exactly three ordered, non-overlapping cues in whole seconds. Frame timecode, multiple tracks, overlapping layers and file imports are outside this tool.

Your entries stay in this browser and are not sent to a sound team. Preparing a sheet does not book a session. A kept copy can be read by someone with access to the same browser profile. Use fictional scene details rather than sensitive client material in this example.

A kept copy belongs to one browser profile and site address. Browser data clearing can remove it. Download exact text for a separate file; Recover kept work restores only the intentionally kept browser copy. Downloaded files cannot be opened back into this editor.
