Your first experiment

The playground opens with A slow double cycle: amplitude 0.8, frequency 2 Hz, phase 0 degrees and offset 0. Its curve completes two cycles in the one-second window.

  1. Open the playground. If you already have work on screen, Reset to example restores these inputs and marks any prepared record stale. It preserves your kept browser copy.
  2. Change Frequency from 2 to 1. The live curve now completes one cycle.
  3. Change Phase to 90. The wave starts at its positive peak.
  4. Change Offset to 0.2. Keep amplitude at 0.8. The center line moves upward.
  5. Name it A raised single cycle, and add the note One cycle, starting at the peak, lifted by 0.2.
  6. Select Prepare the record. The record should show these values and the complete note.

Four ways to change a wave

You can type exact decimal numbers or use the sliders. Amplitude and offset are unitless here; WAVEBENCH assigns no voltage or physical measurement to them.

  • Amplitude A: 0 to 1. Height from the center line to either peak. At 0, the signal is a flat line at the offset.
  • Frequency f: 0.5 to 8 Hz. One hertz means one cycle per second. Half a hertz gives half a cycle in this window.
  • Phase φ: −180 to 180 degrees. The starting angle. A positive 90-degree phase starts at the positive peak when amplitude is above zero.
  • Offset b: −1 to 1. The center of the wave. The possible signal range is b − A to b + A.
y(t) = b + A × sin(2π × f × t + φ × π / 180)
t is time in seconds. The phase angle is converted from degrees to radians inside the sine.

The curve covers t = 0 through t = 1 second. It is drawn from the same formula as the samples, with more points so you can see the shape between them.

Prepare, then inspect

Preparation takes a snapshot of the full signal name, all four parameters and their units, your entire note and all 16 samples. The plotted snapshot and sample tables belong to that prepared record.

The upper graph is live input. The lower graph is the prepared snapshot. Editing any field makes the previous record stale, even if you later put the old value back. Prepare again to make a current record.

Download exact text creates a UTF-8 text file with the same full text shown under the record. Keep browser copy stores that same setup for this browser. Both actions need valid current inputs and a fresh prepared record.

An invalid edit preserves your earlier recordCorrect the marked field, then prepare again. An invalid or stale record cannot be downloaded or kept. The exact earlier output remains visible for comparison.

Read the points as points

Sixteen samples are taken at t = i / 16 seconds, for i = 0 through 15. That means the first time is 0, the spacing is 0.0625 seconds, and the last time is 0.9375 seconds. There is no exported sample at t = 1.

The continuous curve and the samples answer different questions. The curve shows the formula across the whole second; the table shows its values at 16 particular times. At 8 Hz with phase 0 and offset 0, these sample times land on zero crossings, so the exported values are all 0.000000 even though the curve has eight cycles.

Times and sample values are rounded to six decimal places in the text and table. A value that rounds to zero is written as 0.000000, including a tiny negative value. Calculations use the entered decimal parameters before rounding.

Keep one copy, on purpose

Nothing is kept automatically. Prepare a current record, then select Keep browser copy. This replaces WAVEBENCH’s previous kept copy in the same browser and site location.

  • Recover kept copy deliberately replaces the current inputs and prepared record with the exact kept setup, including the full name and note. A reload offers this action; it does not recover automatically.
  • Reset to example restores the starting inputs. Any earlier prepared record becomes stale. The kept browser copy remains available.
  • Forget kept copy removes only WAVEBENCH’s saved setup at this site location. The current inputs and prepared record remain on screen.

If browser storage is blocked, the record stays in memory and a current record can still be downloaded. If a kept copy is damaged, recovery stays unavailable; Forget kept copy can remove it when storage permits.

A browser copy is not a backup service or shared workspace. It does not move between browsers or devices, and it can disappear when site data is cleared. Download anything you want to retain independently.

Limits and corrections

  • Use ordinary decimal numbersEmpty fields, words, nonfinite numbers, exponential notation and values outside the stated ranges are invalid. A blank signal name also blocks preparation. The note may be empty.
  • Watch the live statusAn invalid numeric edit keeps the last valid plot and labels it as the last valid input. Its graph does not claim to represent the invalid entry.
  • Stay with the purposeThis is a visual and numeric educational playground. It makes no sound, connects to no hardware and is not a physical instrument.
  • Your work stays localThe static site has no accounts, upload service or cloud save. Do not rely on browser storage for sensitive or irreplaceable work.
  • Use the exact text for reproductionThe full note and setup remain readable below the record. The downloadable samples are rounded values, not a lossless export of intermediate floating-point calculations.
