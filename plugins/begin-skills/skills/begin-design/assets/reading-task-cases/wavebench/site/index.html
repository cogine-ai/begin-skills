Get to know
the shape

  1. A

    Amplitude

    The distance from the center line to a peak. Try a smaller value and watch the wave flatten.

    0 → 1
  2. f

    Frequency

    Cycles per second. Increase it to fit more repeats into the same one-second window.

    0.5 → 8 Hz
  3. φ

    Phase

    Where the cycle starts. Change the angle to move the pattern along time.

    −180 → 180°
  4. b

    Offset

    The center line. Move it up or down while keeping the wave’s height and pace.

    −1 → 1
