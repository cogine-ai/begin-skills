# Table Nine — source and font notices

Table Nine is an original fictional popup supper-club website and local seating illustration. Its name, invitation, sample menu, HTML, CSS, JavaScript, record layout and guide were created for this exercise. No client images, identities, endorsements or artwork are included.

## Local typefaces

The site embeds unchanged Barlow Condensed ExtraBold, Barlow Regular and Barlow SemiBold binaries from the frozen Begin dev.17 input. The frozen package records their original downloads from the official Google Fonts repository. Exact filenames, upstream URLs, sizes, SHA-256 hashes and frozen input identities are in [FONT_SOURCES.json](FONT_SOURCES.json).

## What runs locally

The seating desk uses only browser JavaScript and optional local storage. It sends no reservation, payment or guest record to a backend. The eight guests and dietary notes are fictional supplied material. This record is not an allergen-safety or medical guarantee.

Supporting files: [starting fixture](fixture.json) and [exact starting export](expected.txt). The text file is UTF-8 without a byte order mark, uses LF line endings and ends in one LF.
