# Compose the useful operation

Use this when the website's value depends on choosing, comparing, editing or keeping something. Start with the real task and its material. Choose a complete page relationship before collecting decorative effects.

## Choose the size of the reference

A complete site can teach how its opening, task and guide share an identity. A block can teach how a choice changes the adjacent explanation. A small component can teach one response or control. Inspect the level that resolves the current uncertainty. A catalogue of attractive primitives does not supply a coherent website by itself.

Write the useful relationship in ordinary language: “keep the selected tree visible while comparing inspection facts,” or “show what the chosen refills cost and what containers to bring.” Then design a new response with the actual content, existing stack and required behavior. Keep reference source, assets and licensing provenance explicit in the project record. Typing a different implementation does not by itself establish permission to reproduce another work.

## Give the task its own composition

Let programme artwork, product containers or operating records lead when that material explains the task. A working desk may be the homepage. A shelf can become a catalogue and itemized result; an event identity can continue into a practical plan. Avoid making every page a heading beside an image.

Use typography roles for the work the letters do. Display character can establish a cultural programme or shop, while dates, names, quantities and actions need comfortable repeated reading. An operational page's tiny identifiers do not become readable merely because the heading uses an appropriate face. Trade introductory framing for legible facts when space is scarce.

Include the actual task heading and practical instructions when comparing type. A short brand specimen cannot establish how a different planner title wraps. Recheck changed wording in its final frame. Keep a short identifier, time range or price basis together when splitting it obscures meaning, while letting surrounding sentences wrap naturally. Avoid retaining every desktop line break on a phone.

Inspect actual changed states. A comparison needs the facts being compared, not just two names. A populated result needs complete identity, useful quantities and an available next action. On a phone, follow the round trip from a later choice to its result and back to continue. Keep a compact count/total jump within reach when it helps; leave the full result in normal flow. A fixed control spends screen space, so inspect its painted position and neighboring content.

## Use movement deliberately

Decide what the visitor needs to notice and what confirms the change. Use a stable selected state, readable feedback or a short transition when it helps. Static artwork can carry an expressive direction while controls remain quiet. A decorative reveal must not stand in for progress, hide essential text or move an action away from the pointer. Review the usable still state, keyboard route and motion preference before relying on an effect.

To try one, copy its entire `site/` directory to a new working directory, including fonts, notices and artwork. Keep an existing project on its own runner. These examples use browser modules: serve the copied directory over local HTTP rather than opening its HTML as a file. If Python is available, run `python3 -m http.server 8000 --bind 127.0.0.1` from that directory and open `http://127.0.0.1:8000/`. Stop that foreground preview with Ctrl+C. Replace the fictional identity and facts, then recheck the actual task and guide. Keep applicable font notices.

[Provenance](../assets/interaction-cases/PROVENANCE.json), [checks](../assets/interaction-cases/CHECKS.json) and [notices](../assets/interaction-cases/NOTICES.md) identify what is delivered. Raw probes, first versions, reviews and full research remain outside installers. The briefs prescribe tasks and fictional facts, leaving fonts and composition open. Makers compared actual font specimens before the first complete source; later review repaired phone round trips, phrase grouping, working-copy recovery and operating hierarchy. This small controlled study supports those particular changes. It does not establish causal first-draft improvement, universal Agent performance or visitor/commercial acceptance.
