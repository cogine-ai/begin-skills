# Choose a font direction in the site's real words

Use this when new subjects keep inheriting the same type family, or when an expressive font looks good in a specimen but weakens the actual page. Respect an accepted brand choice. Develop one important text relationship before spreading it across the site.

## Compare letterforms, then assign roles

Put the actual headline and a representative long name in two plausible families. Keep the words, image and available frame fixed. Compare visible cap height, stroke contrast, width, characteristic letters and word rhythm; equal CSS sizes do not produce equal visible sizes. State what the preferred forms contribute to this subject. A type specimen establishes a local visual preference, not working-page readability or visitor preference.

Choose reading and utility faces separately. Read an instruction paragraph, an accented name, a control and a numeric row. A powerful display face can carry a short identity while a quieter face handles full names, time ranges and explanations. A different brief can justify a different pairing; these examples are options to inspect.

Check the actual font files and supported styles. Anton here is a fixed regular face; increasing its CSS weight would request an unavailable style. Bodoni Moda supplies real roman and italic files with weight and optical-size axes. Syne's heavier weights grow substantially wider, so changing weight can change a word's fit and proportion. Prefer `font-weight` and supported optical sizing to an unnecessary low-level override. Recheck the real words after an axis or role changes.

## Compose complete phrases and local facts

Inspect the longest representative title in the smallest repeated frame, not only the masthead. If a cover needs five fragments or tiny credits to fit, give that item more room or change the phone sequence. Preserve the complete work's name and the relation between author and translator. A column heading that explained a role on desktop needs a local label when the row becomes a phone slip.

Keep short time ranges and value/unit groups together. Allocate the numeric track from the widest actual index, range or amount in the chosen face, with a visible gap before the next fact. When that relationship cannot fit, stack or regroup the facts. Shrinking every label can preserve geometry while damaging reading. Retain ordinary spaces around optional breaks and inline emphasis; inspect the rendered sentence when a callout changes display mode.

A large display opening can suit a public announcement. A selection page may need a smaller role so the choices arrive sooner. Distinguish section headings from item names through useful size, weight or spacing, then inspect long words and phone groups. Align the visible letters, rules, numbers and actions. Give decoration a deliberate position that preserves the word silhouette.

## Evidence and reference boundaries

Primary visual studies included [AKU's Sveta display identity](https://aku.co/projects/sveta-bold-display/), [Pangram Pangram's Editorial New specimen](https://pangrampangram.com/products/editorial-new), and [DEMO's festival identity](https://demofestival.com/), with [Studio Dumbar's account](https://studiodumbar.com/work/demo-2025). They informed tight display forms, contrasted editorial roles and expressive width. Older type-design dates do not establish recent AI-generation methods. Their commercial fonts, screenshots, identities and components are not included in these original cases.

Three first builds used the frozen dev.14 input with explicit task and font-direction suggestions. Full first sources were frozen before rendering. An independent internal reviewer preferred each retained display choice in a labelled A/B specimen; candidate sizes were equal CSS pixels, not matched cap heights. Actual page criticism led to focused revisions. This supports guided font adaptation and concrete repairs. It does not establish automatic font discovery, causal improvement, consistently excellent first drafts, population success, beginner acceptance, all-host/model quality or commercial results. These new examples were absent from the input and require future use evidence.
