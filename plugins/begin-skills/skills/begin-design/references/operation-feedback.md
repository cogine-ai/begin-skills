# Keep the operation legible

Use this for a directly manipulated board, a timed operation or a drawing with an associated editor. Start with what the person needs to recognize and do. Choose typography and composition from the actual material; these examples do not supply a required family, palette or layout.

## Judge the view after the action

An opening can show an attractive board while its Rotate action lives far below it. Inspect the viewport produced by using the actual control. Keep the relevant object and its essential adjustment together when the person must judge them together. A smaller working composition, moving the control or a bounded preview can help. Choose against the actual task and short height; avoid shrinking reading text to keep an oversized scene.

Keep the full output accessible. A small cue can maintain context while editing, but it does not replace a complete object or document. If coordinates are edited separately from prose, their position controls can share a useful view with the anchor while the longer note uses its own reading space. The useful relationship matters more than a persistent panel.

Render one representative changed operation at a narrow, short height before repeating its arrangement across the site. A font specimen establishes letterform fit; this working view tests the relationship between input, feedback and context.

Check the normal keyboard route against the written instructions. Selecting an object, continuing with arrows, rotating, cancelling and reaching the next control should work as described. Preserve a visible destination when a roving control moves to another cell. A correct state model does not establish a usable keyboard path.

## Update identity before movement

A pin's number, selected treatment, note and coordinates describe one subject. When another pin starts moving, establish its context before changing that context's facts. Inspect the gesture before release. A correct final editor can hide a wrong name during dragging.

Direct movement follows the current input. A one-time selection emphasis should not replay on each keyboard nudge. Keep deliberate confirmation, a saved checkpoint, current draft and portable result distinct when the task gives them different meanings. Reuse one representation of the current work when it feeds more than one visible surface.

## Let time mean what the task promises

A rehearsal countdown represents real elapsed time. A creative loop can intentionally hold a chosen phase while absent. Define the promised behavior before adopting a motion lifecycle. For a real timer, returning after several segment boundaries should show the current segment; a paused rehearsal remains held. State local recovery and device-clock limits accurately.

A simple state/color change can be the right response for a frequently used transport control. These tasks do not need decorative entrances to demonstrate motion craft. Keep current identity, remaining time and essential controls readable during the operation.

## Inspect the portable result at its real scale

A numbered anchor inside a large SVG may become unreadable when that entire drawing shrinks on a phone. Inspect the downloaded file itself. Keep marker numbers and their activation targets useful at the supported width, connect them to complete notes, and preserve accurate positions. Keep the note text complete and literal; serialization must not turn a visitor's words into executable markup.
