# Contributing to Begin

## Share an experience

[Open an Issue](https://github.com/cogine-ai/begin-skills/issues/new/choose) with what you wanted to make, which Agent and Begin version you used, what happened and what you expected. A short note is enough. A screenshot or small reproducible example helps when you can share it safely. Remove account details, credentials, private prompts and visitor data.

Use [private security reporting](SECURITY.md) for possible vulnerabilities.

## Suggest an improvement

Start with the user task and the problem. For design changes, show the relevant content and desktop/phone result. Explain when a reference decision helps and when another approach fits better. Keep each Skill independently useful and preserve its complete resources.

This repository is the installable release mirror. Pack development, release builders, maintained tests and private research live in the development repository. Open an Issue before a broad change so maintainers can suggest a practical contribution path. You can send a focused pull request against the editable source here; maintainers carry accepted changes into the maintained source before releasing them. A full release build cannot be reproduced from this mirror alone.

Include relevant reproduction steps or checks with a patch. Submit only material you have the right to contribute. By submitting your original contribution, you agree that it is available under this project's MIT license. Keep existing copyright notices, source attribution and all third-party licenses. Identify any added third-party material and its terms.

## Keep releases fixed

Versioned tags and archives stay fixed. Corrections receive a new version and new integrity receipts. Installation changes must preserve existing instructions, websites, project notes and unrelated Skills through the affected lifecycle operation.
