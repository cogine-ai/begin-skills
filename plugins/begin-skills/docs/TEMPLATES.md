# Choose a starting point

| Starter | Useful for | Adapt it around |
| --- | --- | --- |
| Service | An independent professional or business explaining an offer | The service, approach, relevant work, and contact action |
| Portfolio | A creator showing work | Project sequence, imagery, captions, identity, and exploration |
| Product | A product explaining its value | The actual task, demonstration, feature explanation, and next action |
| Editorial | Articles, a small publication, or documentation | Reading hierarchy, useful index, long-form structure, source notes, and task guides |

Your Agent can choose a sensible starting point and explain why. The starters provide complete source and illustrative content; the release's `CONTENTS.md` identifies the included resources. Read the selected starter's own guide for files, variants, and customization.

Use your own identity, content, images, and destinations. Preserve sample labels while examples remain. Do not turn illustrative projects into claimed client work. Fonts, images, code, and copied material each need their applicable usage terms; the release's `LICENSE_STATUS.md` records the candidate's current licensing status.

A template's layout is a starting composition. Change hierarchy, spacing, typography, colors, media, and component choices to suit your purpose. Keep important states and keyboard behavior when changing the visual direction.

For a reference-led editorial site, the [Fieldnotes worked case](../skills/begin-design/references/fieldnotes.md) includes actual screenshots, design decisions and matching source. It is a separate reference from the creation helper's editorial starter. An Agent should inspect the images and relevant implementation before adapting the case, and choose another direction when its purpose does not fit.

The creation helper copies a starter into a new directory. Existing websites are edited from their current files. Updating Begin changes the pack resources, not the source of sites already created from them.

You can request a different website type. Your Agent should use the relevant professional methods and available implementation, then state any additional work or setup. A planned resource is not an included resource.
