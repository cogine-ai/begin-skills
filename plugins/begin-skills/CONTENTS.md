# Product contents

Versioned resources in this Alpha are listed below. [Status](STATUS.md) records actual checks; the planning baseline is `docs/planning/begin-agent-skill-pack-contents.md` in BeginFleet.

## Start and continue

| Skill | Job |
| --- | --- |
| `begin-setup` | Set up or repair project guidance and a concise `BEGIN.md`; preserve existing files and conventions. |
| `begin-website` | Define the current website task, make or edit it, provide a preview, check the agreed result, and continue. |

Installation is a host operation. Project setup is usually once per workspace; making inspects current conditions without repeating onboarding. People can describe the result they want or request a focused capability directly.

The pack has fifteen independent Skills. This catalog is not an execution sequence. A short task uses the relevant material; more consequential functionality needs a clear behavior contract and deeper checks.

## Declared boundaries

The four starters are static source. The enquiry example has real local persistence and checks; its auth adapter is educational. Researched articles and usable manuals are first-edition tasks. A full editorial calendar, CMS, or distribution operation is additional work. Provider guidance does not establish a configured account or a verified hosted integration. [Status](STATUS.md) separates local checks, Agent tasks, hosts, and remaining work.
